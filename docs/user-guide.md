# Nonet 利用ガイド

## Nonet とは

キーを押している間だけ、MacBook のトラックパッドが「アプリごとに変わる 3×3 の9つのボタン」になるアプリです。

- トラックパッドを縦横3つずつに分け、**指を置いた位置**でマスが決まります（カーソルの位置は関係ありません）
- 慣れたら、キーを押してすぐタップするだけでその場で実行。迷ったときだけ、9マスの一覧（HUD）が画面に出ます
- 前面のアプリに合わせて9マスが切り替わります。1つのアプリに最大3ページ（27マス）まで置けます

### 動作環境

- macOS 14 Sonoma 以降（Apple シリコン・Intel）
- マルチタッチのトラックパッド: MacBook の内蔵トラックパッド、または Magic Trackpad
- AI のアクションだけは、macOS 26 以降で Apple Intelligence が使える Mac が必要です

## はじめに

### インストール

1. ダウンロードした `Nonet-<バージョン>.dmg` を開きます
2. `Nonet` を `Applications` フォルダへドラッグします
3. アプリケーションフォルダから Nonet を開きます

Nonet はメニューバーに常駐するアプリです。Dock には出ません。メニューバーの 3×3 のアイコン（中央が塗りつぶし）が Nonet です。

### アクセシビリティの許可

初めて起動すると案内が出ます。「システム設定を開く」を押し、**システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet をオンにしてください。許可されたことを Nonet が自動で見つけて（2秒ほどで）、次へ進みます。

**なぜ必要か**: macOS では、ほかのアプリを使っている間のキーボードやポインタを扱うのにこの許可が要ります。Nonet は次のことにだけ使います。

- トリガーキーが押された・離されたことを知る
- トリガーキーを押している間、カーソルの移動とクリックを前面のアプリに渡さない
- 設定したキー入力を送る・メニュー項目を押す・選択中のテキストを読む

**集めないもの**: 入力した文字の内容は記録も送信もしません。設定は Mac の中（`~/Library/Application Support/Nonet/`）だけに保存し、アカウントもありません。ネットワークを使うのは、アップデートの確認と購入ページを開くときだけです。トラックパッドの指の位置を読むのに許可は要りません。詳しくは[プライバシーポリシー](privacy.md)をご覧ください。

スクリプトでブラウザの URL を使うときや、ターミナルでコマンドを実行するときは、macOS が初回に「オートメーション」の許可を求めます。

### 初回の案内

1. **アプリを選ぶ**: Mac に入っているアプリのうち、プリセット（最初から用意した9マス）のあるものが並びます。使うものを選んでください。「あとで設定する」で飛ばすこともできます
2. **試してみる**: 練習モードで、案内のとおりにトリガーキーを押しながらタップします。練習中は何も実行されません

案内はメニューバーの Nonet ›「初回の案内をもう一度」で何度でも見られます。

## 基本の使い方

### トリガーキー

9マスにするためのキーです。既定は、JIS 配列のキーボードなら**右⌘**、それ以外なら**右⌥**です（JIS 配列には右⌥がありません）。設定で右⇧や fn にも変えられます。右側のキーだけに反応するので、左の⌘や⌥はいつもどおり使えます。

以下は右⌘の例です。

### 速押し（慣れたら）

1. 右⌘を押します
2. すぐに（0.3秒以内に）実行したいマスの位置をタップします

HUD は出ずに、その場で実行されます。実行したマスは画面の下に一瞬表示されます。右⌘を押したままなら、何度でも続けてタップできます。

### HUD（迷ったら）

1. 右⌘を押します
2. 指をトラックパッドに置いたまま止めます（または、指を置かずに少し待ちます）
3. 9マスの HUD が出て、指の下のマスが白く光ります。指を滑らせて選びます
4. 指を置いたまま右⌘を離すと、光っているマスが実行されます

設定の「実行のタイミング」を「指を離したとき」にすると、4 の代わりに、マスから指を離した時点で実行します。このときは、やめ方も変わります（次の「やめる」）。

### やめる（キャンセル）

どの設定でも:

- 指を置かずに右⌘を離せば、何も起きません
- 右⌘を押している間にほかのキーを押すと、Nonet はすぐに引っ込み、何も実行しません。そのキーは普段どおりアプリに届きます（右⌘＋C なども普段どおり使えます）。やめるためだけに押すなら、**左の⇧**のように、単独で押しても何も起きない修飾キーが安全です

「実行のタイミング」によって:

- **「キーを離したとき」（既定）**: 指を先に離してから右⌘を離すと、何も実行しません
- **「指を離したとき」**: 指を離すと、その時点で光っているマスが実行されます。HUD で選んでいる途中でやめるときは、**指を置いたまま左の⇧を押す**か、空きマスがあれば、そこまで指を滑らせてから離します（空きマスでは何も起きません）

### 押している間のトラックパッド

右⌘を押している間はカーソルが止まり、クリックやスクロールも前面のアプリに届きません。2本以上の指で触れたタップは実行しません。空きマスをタップしても何も起きません。

### ページ

右⌘を押したまま、**2本指で左右にスワイプ**すると前後のページに切り替わります。1回のスワイプで1ページ進み、端では止まります。HUD の下の点が今のページを示します。

アプリのプロファイルの後ろには、グローバルのページがつながります（設定で切り替えられます）。

### ランチャー

どのアプリでも使える「グローバル」のプロファイルは、最初は Mac に入っているよく使うアプリを最大9個並べたランチャーです。macOS 26 で無くなった Launchpad の代わりに使えます。プロファイルの無いアプリの前では、グローバルのページが使われます。

### 触覚

指がマスの境界をまたぐたびに、トラックパッドが軽く「コツッ」と振動します。ページが変わったときと実行したときにも振動します。強さは設定で選べます。

## プロファイルを編集する

メニューバーの Nonet ›「設定…」または「プロファイルを編集…」で設定のウィンドウを開きます。

- **左（サイドバー）**: グローバルと、アプリのプロファイルの一覧。ドラッグで並べ替え、右クリックで削除・無効化。「プロファイルを追加」でインストール済みのアプリを選ぶと、プリセットがあればその中身で作ります
- **中央**: ページの切り替え（最大3ページ）と 3×3 のマス
  - クリックで選ぶ、ドラッグで入れ替える、Delete キーで空にする
  - 右クリックで複製・削除・「このマスをテスト実行」
- **右（インスペクタ）**: 表示名・アイコン（SF Symbols・アプリのアイコン・1〜2文字）・アクションの種類と中身

### メニューから割り当てる

ショートカットを調べなくても、アプリのメニューから選んで割り当てられます。

1. 対象のアプリを起動しておきます
2. 設定のウィンドウで「メニューから割り当て」を開き、アプリを選びます
3. 検索して、項目を空いたマスへドラッグします（ダブルクリックでも入ります）

### 書き出しと読み込み

プロファイルを `.nonetprofile` のファイルに書き出して、バックアップしたりほかの人と共有したりできます。**ほかの人から受け取ったプロファイルを読み込むときは、中のスクリプトを必ず確かめてください**（スクリプトはあなたの権限で動きます）。

## アクションの種類

### キー入力

前面のアプリにキーを送ります。記録欄を選んで、送りたいキーをそのまま押すと記録されます。

- `⌘B`、`⇧⌘4` のような組み合わせ
- `⌘L → ⌘C` のような、続けて押すキー（40ミリ秒の間隔で送ります）

JIS 配列でも、`⌘[` などが正しく届きます。

### アプリを開く

起動していなければ起動し、起動中なら前面に出します。「前面のときは隠す」をオンにすると、もう一度押したときに隠れるので、アプリの切り替えのように使えます。

### URL

既定のアプリで開きます。`https://` を省いた場合は自動で付けます。`obsidian://` のような、アプリ独自の URL も使えます。

### スクリプト

zsh のスクリプトを実行します（`/bin/zsh -l -c`）。

- **実行の仕方**
  - 裏で実行: 終わるまで待ちます。制限時間（既定 60秒）を過ぎると止めます。失敗したら（終了コードが 0 以外）、エラー出力の最後の部分を画面に表示します
  - ターミナルで実行: ターミナルの新しいウィンドウで実行します。`claude` のような対話型のコマンドに向いています
- **作業フォルダ**: プロジェクトのフォルダ（下記）。分からなければホームフォルダ
- **環境**: ログインシェルなので `~/.zprofile` は読まれますが、`~/.zshrc` は読まれません。Homebrew などの `PATH` は `~/.zprofile` に書いてください

#### スクリプトに渡す環境変数

実行したときの前面のアプリの情報を渡します。**値が無いものは設定されません**。

| 変数 | 中身 | 例 |
|---|---|---|
| `NONET_APP_BUNDLE_ID` | 前面のアプリの bundle ID | `com.apple.dt.Xcode` |
| `NONET_APP_NAME` | 前面のアプリの名前 | `Xcode` |
| `NONET_DOCUMENT_PATH` | 前面のウィンドウで開いている書類 | `/Users/you/dev/App/App.xcodeproj` |
| `NONET_PROJECT_DIR` | 書類から決めたプロジェクトのフォルダ | `/Users/you/dev/App` |
| `PROJECT_DIR` | `NONET_PROJECT_DIR` と同じ | `/Users/you/dev/App` |
| `NONET_BROWSER_URL` | ブラウザで表示中のページ（Safari・Google Chrome・Arc・Microsoft Edge・Brave） | `https://example.com/article` |
| `NONET_SELECTED_TEXT` | 選択中のテキスト | |

プロジェクトのフォルダは次のように決めます。

- 書類が `.xcodeproj`・`.xcworkspace`・`.swiftpm` なら、その入っているフォルダ
- ほかのファイルなら、上へたどって `.git` か `Package.swift` のあるフォルダ。見つからなければ、そのファイルのあるフォルダ

例:

```zsh
# Claude Code をプロジェクトのフォルダで開く（「ターミナルで実行」）
cd "$PROJECT_DIR" && claude

# プロジェクトを VS Code で開く
open -a "Visual Studio Code" "${PROJECT_DIR:-$HOME}"

# 表示中のページの URL をクリップボードへ
printf '%s' "${NONET_BROWSER_URL:?ブラウザが前面にありません}" | pbcopy
```

変数は必ず `"$NONET_SELECTED_TEXT"` のように `"` で囲んでください（空白や記号を含むことがあります）。無いかもしれない変数は `${変数:-既定値}` か `${変数:?メッセージ}` で扱うと安全です。`:?` のメッセージは失敗として画面に出ます。

### ショートカット

ショートカット.app のショートカットを名前で選んで実行します。「選択中のテキストを渡す」をオンにすると、選択中のテキストを入力として渡します。

### メニュー項目

アプリのメニュー項目を押します。「メニューから割り当てる」で選ぶのがかんたんです。

- 対象のアプリが前面にあり、その項目にショートカットがあれば、キーを送ります（速い）
- 無ければ、アクセシビリティの機能でメニューを順にたどって押します
- 対象のアプリが起動している必要があります
- メニューの名前は macOS の言語で変わります。言語を変えたら割り当て直してください

### AI

選択中のテキストと指示文を、Mac の中の言語モデル（Apple Intelligence）に渡します。テキストが Mac の外に送られることはありません。

- 必要なもの: macOS 26 以降、Apple Intelligence に対応した Mac、**システム設定 › Apple Intelligence と Siri** で Apple Intelligence をオン（モデルのダウンロードが終わっていること）
- 結果の出し方: 選択範囲を置き換える / クリップボードにコピー / 画面に表示
- 使えない Mac では、実行したときに理由を表示します

## 設定

メニューバーの Nonet ›「設定…」で開きます。

| 設定 | 既定 | 内容 |
|---|---|---|
| Nonet を有効にする | オン | オフにするとトリガーキーに反応しません。メニューバーからも切り替えられます |
| トリガーキー | JIS は右⌘、ほかは右⌥ | 右⌘・右⌥・右⇧・fn。JIS 配列で右⌥を選ぶと警告が出ます |
| 実行のタイミング | キーを離したとき | HUD で選んだマスを、トリガーキーを離したときに実行するか、マスから指を離したときに実行するか。速押しはどちらでもその場で実行します。「指を離したとき」では、やめ方が変わります（「基本の使い方」の「やめる」） |
| HUD が出るまでの時間 | 0.3秒 | 0.15〜0.8秒。この時間より早いタップは速押しとして扱います |
| HUD の位置 | 画面の中央 | 画面の中央 / カーソルの近く。カーソルのあるディスプレイに出ます |
| 前面のアプリで切り替える | オン | オフにすると、いつもグローバルのプロファイルを使います |
| グローバルのページをつなげる | オン | アプリのページの後ろにグローバルのページをつなげ、2本指スワイプで行けるようにします |
| 触覚 | 中 | オフ / 弱 / 中 / 強 |
| トリガーキーを前面のアプリに渡す | オン | オフにすると、トリガーキーそのものを前面のアプリに渡しません（下の「困ったとき」も参照） |
| 実行を知らせる | オン | HUD を出さずに実行したとき、実行したマスを画面の下に一瞬表示します |
| カーソルの固定方法（詳細） | 自動 | 自動（移動を捨て、ずれたら元に戻す）/ 移動を捨てる / カーソルを切り離す / 固定しない。カーソルが動いてしまうときに変えてみてください |
| ログイン時に起動 | | Mac にログインしたときに Nonet を起動します |
| プロファイルの書き出し / 読み込み | | `.nonetprofile` のファイルで |

設定のウィンドウにはほかに、**ライセンス**（試用の残り日数・登録者・キーの入力・購入ページ）と**情報**（バージョン・アップデートの確認・このガイド・プライバシーポリシー）があります。

## 試用とライセンス

- 初めて起動した日から**14日間**、すべての機能を無料で使えます。残り日数はメニューバーのメニューと設定の「ライセンス」に出ます
- 試用期間が終わると、HUD に「試用期間が終了しました」と表示され、マスを押しても実行されません。設定はそのまま残ります
- 購入すると、ライセンスキーがメールで届きます。設定の「ライセンス」に貼り付けると、すぐに使えるようになります。キーは Mac の中で確かめるので、ネットワークもアカウントも要りません

## アップデート

新しい版は自動で確認され、見つかると知らせが出ます。メニューバーの Nonet ›「アップデートを確認」でいつでも確認できます。

## 困ったとき

### カーソルが動かない・クリックが効かない

トリガーキーを押している間は、カーソルとクリックを止めています。キーが押されたままと判断されているときは、次のどれかで戻ります。

- トリガーキー（右⌘など）を一度押して離す
- 何かほかのキーを押す（その場で中断されます）
- 20秒待つ（長すぎる操作は自動で終わります）
- それでも戻らなければ、メニューバーの Nonet ›「終了」

### まったく反応しない

- メニューバーのアイコンが「無効」や「許可が必要」の見た目になっていないか確かめます。メニューを開くと状態が表示されます
- **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet がオンか確かめます。アップデートの後に効かなくなった場合は、一覧から Nonet を「−」で外し、もう一度追加してオンにしてください
- **パスワードの入力中は動きません**。パスワード欄にカーソルがあるときや、ターミナルの「セキュアキーボード入力」がオンのとき、macOS はほかのアプリにキーを見せません。パスワード欄から離れるか、ターミナル › セキュアキーボード入力 をオフにしてください
- 設定の「Nonet を有効にする」がオンか確かめます

### JIS キーボードで右⌥が見つからない

JIS 配列には右⌥がありません。トリガーキーを右⌘（既定）・右⇧・fn のどれかにしてください。

⌘英かな や Karabiner-Elements などで「右⌘の単押し」を使っている場合、Nonet を使うたびにそちらも反応することがあります。トリガーキーを別のキーにするか、そのツールの設定を変えてください。「トリガーキーを前面のアプリに渡す」をオフにすると、ほかのアプリやツールにトリガーキーが届かなくなります。

### Magic Trackpad で使いたい

Magic Trackpad でも使えます。つないだ後に反応しないときは、Nonet を終了して起動し直してください。マウスだけの Mac では使えません。

### タップしたマスと違うものが実行される

マスはトラックパッドの**絶対的な位置**で決まります。端のマスはトラックパッドの端の方をタップしてください。迷ったら指を置いて止まり、HUD で確かめてから実行できます。速押しが速すぎて HUD が出る、または遅すぎて HUD が出ないと感じたら、「HUD が出るまでの時間」を変えてください。

### スクリプトが失敗する

- 画面に出たエラーを確かめます。`command not found` なら、`PATH` を `~/.zprofile` に書いてください（`~/.zshrc` は読まれません）
- ターミナルで `zsh -l -c '<スクリプト>'` を実行すると、同じ条件で試せます
- 時間がかかる処理は、制限時間を延ばすか「ターミナルで実行」にしてください
- ブラウザの URL やターミナルでの実行が拒否されたときは、**システム設定 › プライバシーとセキュリティ › オートメーション** で Nonet の項目をオンにします

### AI のアクションが使えない

macOS 26 以降か、Apple Intelligence がオンでモデルのダウンロードが終わっているか、Mac が Apple Intelligence に対応しているかを確かめてください。

### 振動しない

設定の「触覚」がオフになっていないか確かめます。振動は感圧タッチ（Force Touch）のトラックパッドでだけ感じられます。

### 設定を最初に戻したい

Nonet を終了してから `~/Library/Application Support/Nonet/` をゴミ箱に入れ、もう一度起動すると、初回の状態から始まります。

## アンインストール

1. 設定で「ログイン時に起動」をオフにします
2. メニューバーの Nonet ›「終了」
3. アプリケーションフォルダの `Nonet` をゴミ箱に入れます
4. 次のファイルとフォルダを消します
   - `~/Library/Application Support/Nonet/`（設定）
   - `~/Library/Preferences/com.iam74k4.Nonet.plist`（試用の開始日とライセンスキー。また使う予定があれば、キーを控えてから消してください）
   - `~/Library/Caches/com.iam74k4.Nonet/`（アップデートの一時ファイル）
5. **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet を選び、「−」で外します。ターミナルで `tccutil reset Accessibility com.iam74k4.Nonet` を実行しても同じです
