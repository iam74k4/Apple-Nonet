## Nonet とは

トラックパッドの上の縁から指を滑らせると、MacBook のトラックパッドが「アプリごとに変わる 3×3 の9つのボタン」になるアプリです。操作はトラックパッドだけで済み、キーは使いません。

- トラックパッドの上の縁に指を置いて下へ滑らせると、9マスが開きます。そのまま指を滑らせて選び、マスで離すと実行します
- トラックパッドを縦横3つずつに分け、**指の位置**でマスが決まります（ポインタの位置は関係ありません）。開いている間は、9マスの一覧（HUD）が画面に出ます
- 迷ったら、9マスの外側の外枠まで滑らせて離せば、何も実行せずに閉じます
- 前面のアプリに合わせて9マスが切り替わります。1つのプロファイルに最大3ページ（27マス）まで置けます

### 動作環境

- macOS 14 Sonoma 以降（Apple シリコン・Intel）
- マルチタッチのトラックパッド: MacBook の内蔵トラックパッド、または Magic Trackpad。マウスだけの Mac では使えません
- AI のアクションだけは、macOS 26 以降で Apple Intelligence が使える Mac が必要です

## はじめに

### インストール

1. ダウンロードした `Nonet-<バージョン>.dmg` を開きます
2. `Nonet` を `Applications` フォルダへドラッグします
3. アプリケーションフォルダから Nonet を開きます

ディスクイメージの中やダウンロードしたままの場所から開くと、そこからはアップデートを入れられないため、「Nonet をアプリケーションフォルダに移しますか？」と確かめます。「アプリケーションフォルダに移す」を押すと、移してから開き直します（管理者でないアカウントでは、ホームフォルダの中の「アプリケーション」に移します）。アプリケーションフォルダにすでに Nonet があるときは、置き換えてよいかをもう一度確かめ、前の Nonet はゴミ箱に入れます。どちらのフォルダにも移せないときは、Finder で移す方法を案内します。

Nonet はメニューバーに常駐するアプリで、Dock には出ません。メニューバーの 3×3 のアイコン（中央が塗りつぶし）が Nonet です。このガイドでは、このアイコンを押すと開くメニューを「Nonet のメニュー」と呼びます。

Nonet は同時に1つしか動きません。動いているときにもう一度開くと、新しく起動する代わりに、動いている Nonet の設定のウィンドウがすぐに開きます。終了した直後に開いたときは、前の Nonet が終わるのを待ってから起動します。ディスクイメージから開いた Nonet とアプリケーションフォルダの Nonet が重なったときは、アプリケーションフォルダの方が動きます。ただし、ディスクイメージの方が新しい版なら、そちらが動きます（アプリケーションフォルダの Nonet が動いていれば終わらせてから起動し、「Nonet をアプリケーションフォルダに移しますか？」と確かめます）。ディスクイメージの方が新しくないときは、「Nonet はすでに動いています」と知らせて終わり、動いている Nonet の設定のウィンドウが開きます。

### アクセシビリティの許可

初めて起動すると「Nonet へようこそ」のウィンドウ（初回の案内）が開きます。「システム設定を開く」を押すと macOS の確認が出るので、そこから **システム設定 › プライバシーとセキュリティ › アクセシビリティ** を開き、Nonet をオンにしてください（パスワードか Touch ID を求められます）。確認が出ないときや、もう一度押したときは、システム設定のその欄が開きます。許可すると、システム設定の後ろに隠れた案内のウィンドウが自動で前に戻り、次へ進みます。

**なぜ必要か**: macOS では、ほかのアプリを使っている間のポインタやキーボードを扱うのにこの許可が要ります。Nonet は次のことにだけ使います。

- 9マスを開いている間、ポインタの移動とクリックを前面のアプリに渡さない
- 9マスを開いている間に、キーが押されたことを知る（何も実行せずに閉じるため）。9マスを開いていない間は、キーボードを見ません
- 設定したキー入力を送る・メニュー項目を押す・選択中のテキストを読む

**集めないもの**: 入力した文字の内容は記録も送信もしません。設定は Mac の中（`~/Library/Application Support/Nonet/`）だけに保存し、アカウントもありません。ネットワークを使うのは、アップデートの確認と購入ページを開くときだけです。トラックパッドの指の位置を読むのに許可は要りません。詳しくは[プライバシーポリシー](privacy.md)をご覧ください。

「あとで許可する」で先へ進むこともできますが、許可するまで Nonet は動きません（案内の上に並んだ段階の「アクセシビリティ」に「!」が付きます）。許可しないまま終えると、次に起動したときに「Nonet を使うには、あと1つ許可が必要です」の画面が開きます。「今後表示しない」を選ぶと、もう開きません。あとから許可するときは、Nonet のメニューの「アクセシビリティを許可…」（この画面が開きます）か、設定のウィンドウの上に出る帯の「システム設定を開く」を使います。トラックパッドが見つからないときは、この画面でも知らせ、「もう一度確かめる」で探し直せます。

ファイルのアクションを初めて使うときと、スクリプトでブラウザの表示中のページの URL（`NONET_BROWSER_URL`）を使うときは、macOS が初回に「オートメーション」の許可を求めます（「困ったとき」の「[オートメーションの許可を求められた](#オートメーションの許可を求められた)」）。

### 初回の案内

「Nonet へようこそ」のウィンドウは、上に並んだ2つの段階で進みます。

1. **アクセシビリティ**: 上の許可です
2. **試してみる**: 練習モードで2つ試します。図には、いま HUD に出るマスの名前が並びます。1つ目は「開いて、マスで離す」: トラックパッドの上の縁に指を置いて下へ滑らせ、HUD が開いたら案内のマスまで指を滑らせて、そこで離します（違うマスで離したときは、案内のマスがどこにあるかを教えます）。2つ目は「外枠で離して、やめる」: もう一度上の縁から開き、今度は指を外枠（9マスの外側）まで滑らせてから離します。練習中は何も実行されません。「スキップ」で飛ばせます。試せないときは、理由と直すためのボタンが出ます。Nonet が無効なら「Nonet を有効にする」、トラックパッドがなければ「もう一度確かめる」、いま使うページのマスがすべて空いていれば「設定を開く」、試用期間が終わっていれば「ライセンスキーを入力…」（ライセンスキーを登録すると、この知らせは消えます）

練習の画面の下には「戻る」「設定を開く」と、2つとも済めば「完了」（済んでいなければ「スキップ」）があります。「完了」か「スキップ」で閉じると、メニューバーの Nonet のアイコンが光り、その下に「Nonet はここにいます」と出ます。「設定を開く」を押すと、そのまま設定のウィンドウが開きます。

最初の設定には、Mac に入っているアプリのうち、プリセット（最初から用意した9マス）のあるもののプロファイルがすべて入っています（Finder・Safari・Chrome・Arc・メール・Outlook・Zoom・Teams・Slack・Excel・Word・PowerPoint・Keynote・Pages・Numbers・Notion・メモ・Obsidian・Figma・Photoshop・Final Cut Pro・Xcode・Visual Studio Code・Cursor・ターミナル）。要らないプロファイルは、設定の「プロファイル」のタブで削除します。Apple Intelligence を使えない Mac では AI のマスを、`claude` コマンドのない Mac では Claude Code のマスを入れず、中央には代わりのマスを置きます。AI のマスの代わりに中央へ移したマスの元の位置には、別のマスが入るので9マスのままです（Claude Code のマスは、どのプリセットでも中央には置きません）。

グローバルのプロファイルには、Mac にあるよく使うアプリを並べたランチャーが入ります（「基本の使い方」の「[グローバルとランチャー](#グローバルとランチャー)」）。

案内は Nonet のメニューの「初回の案内をもう一度」で何度でも見られます。

## 基本の使い方

### 開く

1. トラックパッドの上の縁（奥の端）に指を1本置きます
2. そのまま、すっと下へ滑らせます

9マスが開いて HUD（9マスの一覧）が画面に出て、トラックパッドが軽く振動します。ポインタは指を置いた位置に戻り、閉じるまで止まります。開いた瞬間の指はまだ外枠（9マスの外側）にいるので、HUD には「✕ 離すとやめる」が出ます。ここで離せば、何も実行せずに閉じます。

- 上の縁（奥の端から 9mm ほど）に置いた指を、触れてから 0.6秒のうちに 5mm ほど下へ動かすと開きます。真下でなくても、斜めに滑らせれば開きます（横へ動いた距離が、下へ動いた距離の 1.5 倍までです。距離は、トラックパッドの幅と奥行きをそれぞれ 1 としたときの割合で測るので、実物では横へ少し寝た動きまで開きます）。触れてから 0.6秒たってから動かし始めたときと、縁に沿って横へ動かしたときは、ふつうのポインタの移動として扱います
- 開く動きを見分けてから、0.04秒ほど待って開きます。その間に2本目の指が触れたとき（2本指のスクロールの始まり）や指が離れたときは、開きません
- 速さは見ていません。奥の端から 9mm 以内に指を置いて、そのまま下へポインタを動かすと、ふつうのポインタ操作でも開きます。ポインタを動かすときは、奥の端から離れたところに指を置いてください。よく開いてしまうときは、設定の「開きやすさ」を「控えめ」にすると、帯が 6mm ほどに狭まり、0.4秒のうちに 7mm ほど動かしたときだけ開きます。逆に、縁から滑らせても開かないことがあるときは「開きやすい」にします（帯 13mm ほど、1秒のうちに 4mm ほど）
- 2本以上の指や手のひらで触れたとき、縁より手前から指を滑らせてきたとき、マウスやトラックパッドのボタンを押したままのとき（クリックしたままドラッグするときなど）は開きません
- 設定や初回の案内など、Nonet のウィンドウが前面にあるときも開きません（設定では、マスのドラッグなどにトラックパッドを使うため）。Nonet を起動してから最初の1回だけ、画面の下に「Nonet のウィンドウが前面のときは、9マスは開きません」と出ます。ほかのアプリの上で試してください
- HUD はポインタのあるディスプレイに出ます（設定の「HUD の位置」）

### 選んで実行する

1. 指を置いたまま滑らせて、マスを選びます。指の下のマスが目立つ色に反転し（ダークでは白く、ライトでは黒く塗られます）、マスの境界をまたぐたびにトラックパッドが軽く振動します
2. 実行したいマスで指を止めて、そのまま離します

光っているマスが実行され、HUD が閉じます。

- マスで少し（0.1秒）止まってから離したときだけ実行します。狙ったマスへ滑らせて、そのまま離せば届く短さです。滑らせながら離したときや、通りかかっただけのマスは実行しません（ポインタを動かすつもりで指を滑らせたときに、マスを実行しないため）
- マスとマスの境目の線のほぼ真上（線の両側 2mm ほど）で離したときは、どちらを狙ったか分からないので実行しません
- マスはトラックパッドの**位置**で決まります。左上のマスは、トラックパッドの左上（外枠の内側）にあります
- HUD の上の縁には、プロファイルの名前が出ます（ページに名前を付けていれば「Xcode · デバッグ」のように名前も）。ページが複数あるときは、その右に点が並び、今のページを示します。マスにはアイコンと名前だけが出て、押すキー（⌘B など）は出しません。少し長く止めるマスを止めている間は、名前の右に「そのまま止めて待つ」「離すと実行」が出ます。練習中は「練習中」が出ます

### やめる（キャンセル）

次のどれでも、何も実行せずに閉じます。外枠・空きマス・境目の線の上で離したときと、2本の指で離したときは、軽く2回振動します。キーで閉じたときと、時間切れで閉じたときは、振動しません。

- **外枠で離す**: 9マスの外側の外枠まで指を滑らせて離します。外枠は、トラックパッドの左右の端から幅の 11%、手前の端から奥行きの 15%、奥の端から 17% の帯です（幅 15cm ほどのトラックパッドで 1.5〜1.7cm）。指が外枠に入ると、マスが暗くなって外枠が明るくなり、「✕ 離すとやめる」が出ます
- **キーを押す**: 開いている間にどれかのキー（音量・輝度などのメディアキーを除く）を押すと、すぐに閉じます。そのキーは普段どおりアプリに届きます
- **空きマスで離す**: 中身のないマスで離しても、何も起きません
- **境目の線の上で離す**: マスとマスの境目では実行しません

開いたまま20秒たつと、自動で閉じます。

### 少し長く止めるマス

送信や録画のように取り消せない操作のマスは、インスペクタの「少し長く止めてから実行」をオンにしておくと安心です。

- このマスには、HUD の角に印が付きます
- そのマスで指を少し（0.45秒）止めると、マスの縁が一周します。止めている間は HUD の右上に「そのまま止めて待つ」と出て、一周するとトラックパッドが1回振動し、「離すと実行」に変わります。一周してから離すと実行します。一周する前に離すと、何も実行しません

### 開いている間のトラックパッド

9マスを開いている間はポインタが止まり、クリックやスクロールも前面のアプリに届きません。指をトラックパッドに載せたまま外付けのマウスを使うと、そのクリックや移動も捨てられます（指を離すと閉じて、元に戻ります）。トラックパッドに触れていないときに届いたマウスの操作は、何も実行せずに閉じ、その操作はそのままアプリに届きます（指が離れたことを取りこぼしたときの備えです）。2本の指を置いたまま離したときも、何も実行しません。

### ページ

9マスを開いたまま、指を**左右の外枠に止める**と、そちら側のページに切り替わります。右の外枠なら次のページ、左の外枠なら前のページです。

1. 指を左右どちらかの外枠（9マスの行の横。角は除く）まで滑らせ、そのまま止めます
2. 0.5秒ほどでページが切り替わり、トラックパッドが2回振動します。止めたままなら、0.9秒ごとにさらに1ページ進みます
3. 指をマスへ滑らせて選び、離して実行します

止めている間は、その側の外枠の帯に線が伸びていき、「✕ 離すとやめる」の下に「止めると次のページ」（左なら「止めると前のページ」）が出ます。外枠で離せば、ページを切り替えた後でも、いつもどおり何も実行せずに閉じます。端のページから先へは進みません。HUD の下の点が今のページを示します。アプリのページとグローバルのページの点の間は少し空いています。

**2本指で左右にスワイプ**しても切り替えられます。2本指を左へ動かすと次のページで、1回のスワイプで1ページ進みます。端では止まり、軽く2回振動します。スワイプした後は、指を1本だけ離し、残った指をもう一度滑らせてからマスで離します。滑らせずに離したときと、2本とも離したときは、何も実行しません。

1つのプロファイルに最大3ページまで置けます。アプリのプロファイルの後ろには、いつもグローバルのページがつながります。

### グローバルとランチャー

前面のアプリにプロファイルがあれば、そのアプリの9マスを使います。プロファイルのないアプリの前では、どのアプリでも使える「グローバル」のプロファイルを使います。

グローバルのプロファイルは、最初はよく使うアプリを最大27個（3ページ）並べたランチャーです。Dock に置いてあるアプリを Dock の順に先に並べ、残りを Mac に入っているよく使うアプリで埋めます。macOS 26 でなくなった Launchpad の代わりに使えます。中身はほかのプロファイルと同じように自由に変えられます。

### 触覚

9マスが開いたときと、指がマスの境界をまたぐたびに、トラックパッドが軽く「コツッ」と振動します。実行したときと、少し長く止めるマスを止め終えたときは1回、ページが変わったときは2回振動します。何も実行せずに閉じたとき（外枠・空きマス・境目の線の上で離した・2本の指で離した・最後のページから先へのスワイプなど）と、試用期間が終わっていて開かないときは、軽く2回振動します。キーで閉じたときと、時間切れのときは振動しません。設定の「触覚」でオフにできます（感圧タッチのトラックパッドでだけ振動します）。

## メニューバー

メニューバーの 3×3 のアイコンを押すと、Nonet のメニューが開きます。

| 項目 | 内容 |
|---|---|
| 状態（いちばん上の行） | 動作中なら「Xcode のプロファイル」「グローバルのプロファイル」のように、前面のアプリで使うプロファイルを表示します。問題があれば「アクセシビリティの許可が必要です」「トラックパッドが見つかりません」「パスワード入力中は使えません」「Nonet は無効です」などを表示します。試用期間が終わったときは「試用期間が終了しました」、残り3日以下なら「試用期間は残り3日です」のように出ます |
| アクセシビリティを許可… | 許可がないときだけ出ます。初回の案内の許可の画面を開きます |
| この知らせを消す | 設定ファイルを読めなかったときなどに、知らせと一緒に出ます |
| 早見表 | 前面のアプリで9マスを開いたときに出るマスを、最初のページから並べます。‹ › でほかのページも見られます。マスをクリックすると、設定の「プロファイル」のタブでそのマスを開きます。前面のアプリで Nonet を使わない設定なら、マスの代わりに「Xcode では Nonet を使いません」のように出ます |
| Nonet を有効にする | チェックを外すと、上の縁から指を滑らせても9マスが開かなくなります |
| 設定… | 設定のウィンドウを「一般」のタブで開きます |
| Xcode のマスを編集… / Pages のマスを作る… / グローバルのマスを編集… | 前面のアプリのマスを、設定の「プロファイル」のタブで開きます。プロファイルがなければ（プリセットがあればその中身で）作ります。1分以内にそのプロファイルのマスを実行していれば、そのマスを選びます。前面のアプリが分からないときは、グローバルのマスを開きます |
| このアプリでは使わない | 前面のアプリで Nonet を使わないようにします（チェックが付きます）。そのアプリでは、上の縁から指を滑らせても9マスは開かず、トラックパッドはいつもどおり働きます。もう一度選ぶと元に戻ります（「プロファイルを編集する」の「[プロファイルの一覧](#プロファイルの一覧)」） |
| 最近の実行 | 最近実行したマスを新しい順に10個まで、「✓ Xcode › ビルド」のように並べます。失敗したものは「✗」と理由の1行目が付きます。選ぶと、設定の「プロファイル」のタブでそのマスを開きます |
| 初回の案内をもう一度 | 「Nonet へようこそ」のウィンドウを開きます |
| 利用ガイド | このガイドを開きます |
| 試用期間：残り14日 / 登録済み / 試用期間が終了しました | ライセンスの状態です。「登録済み」を選ぶと、設定のウィンドウを「Nonet」のタブで開きます。状態の行と同じことは繰り返しません |
| Nonet を購入… / ライセンスキーを入力… | 試用中と、試用期間が終わった後に出ます。「Nonet を購入…」は購入ページを、「ライセンスキーを入力…」は設定の「Nonet」のタブを開きます |
| アップデートを確認 | 新しい版があるか確かめます。自動の確認で新しい版が見つかっているときは「アップデートがあります…」に変わり、選ぶとその知らせを出します |
| 終了 | Nonet を終了します |

アイコンの見た目でも状態が分かります。無効のときは薄くなります。確かめてほしいことがあるとき（許可がない・トラックパッドが見つからない・パスワードの入力中・試用期間の終了や残り3日以下・知らせがある）は右上のマスが「!」に変わり、理由はメニューのいちばん上の行に出ます。新しい版が見つかったときは、右上のマスが点に変わります。

設定や初回の案内のウィンドウが前にあるときは、⌘?（「Nonet ヘルプ」）でもこのガイドを開けます。

## プロファイルを編集する

Nonet のメニューの「◯◯ のマスを編集…」（◯◯は前面のアプリ）で、設定のウィンドウの「プロファイル」のタブを開きます。左から、プロファイルの一覧・9マス・インスペクタの3つの列に分かれています。

### プロファイルの一覧

- いちばん上の「グローバル」（「既定」の印）は、プロファイルのないアプリで使う9マスです。消すことはできません
- その下の「アプリ」に、アプリのプロファイルが並びます。ドラッグで並べ替えられます。いま前面のアプリで使われているプロファイルには「使用中」の印が付きます
- 「プロファイルを追加」で、インストール済みのアプリから選んで作ります。プリセットのあるアプリは、最初から中身が入ります。一覧にないアプリは「一覧にないアプリを選ぶ…」で選べます
- プロファイルを右クリック（Control キーを押しながらクリック）すると、「前面にあるとき」の3つの選択肢と、「複製して別のアプリに使う…」「プリセットに戻す…」（プリセットのあるアプリだけ）「このプロファイルを書き出す…」「削除…」が出ます。Delete キーでも削除できます。削除する前に確かめます（⌘Z で元に戻せます）
- **前面にあるとき**: 9マスの右上（またはプロファイルの右クリック）で、そのアプリが前面にあるときの使い方を「このプロファイル」「グローバルを使う」「このアプリでは Nonet を使わない」から選べます。「グローバルを使う」にしたプロファイルには「グローバル」の印が付き、そのアプリの前でもグローバルのマスを使います（このプロファイルのマスは残ります）。「このアプリでは Nonet を使わない」にしたアプリには「オフ」の印が付きます。そのアプリでは、上の縁から指を滑らせても9マスは開かず、トラックパッドもキーもいつもどおり働きます。Nonet のメニューの「このアプリでは使わない」でも切り替えられます
- アプリのプロファイルが8個以上あると、一覧の上に「名前・マス・キーで絞り込み」の欄が出ます（⌘F でいつでも出せます。Esc か ×（絞り込みをやめる）で閉じます）。プロファイルの名前と、どのプロファイルのマスの名前・中身・送るキー（`⌘B` のように修飾キーを付けて入れます）でも探せ、結果は「Xcode › ビルド」のように並びます
- 一覧の下の「Nonet を有効にする」は、一般の設定と同じスイッチです

### ページと9マス

中央に、選んだプロファイルのページと 3×3 のマスが出ます。

- 「ページ 1」「ページ 2」…（⌘1〜⌘3）で切り替えます。「＋」（ページを追加）で増やし（最大3ページ）、ページの横の「…」（ページの操作）の「このページを削除…」か、ページを右クリックして「このページを削除…」で、選んでいるページを消します。中身のあるマスがあるページは、消す前に確かめます。「…」からは、ページの追加と「名前を変更…」もできます
- ページのボタンをダブルクリックするか、右クリックして「名前を変更…」を選ぶと、「デバッグ」「Git」のようにページに名前を付けられます。名前は HUD の題名にも「Xcode · デバッグ」のように出ます。空にすると「ページ 1」などに戻ります
- マスをクリックで選び、ドラッグで入れ替えます。「ページ 2」などの上へドラッグすると、そのページの空きマスへ移ります
- 矢印キーで選ぶマスを移り、Delete キーで空にします。ほかのキーは「作り込むときの操作」
- マスを右クリックすると「複製」「削除」「このマスをテスト実行」が出ます。空きマスでは「アクションを追加」から種類を選んで作れます。コピーと貼り付け、隣との入れ替えはキーで行います（「作り込むときの操作」）

### 元に戻す・以前の設定に戻す

- マスの変更（空にする・削除・複製・作る・入れ替える・ほかのページへ移す・メニューから割り当てる・貼り付ける）、インスペクタでの変更（マスごとに1つ）、ページの追加と名前の変更、「プリセットに戻す…」、「複製して別のアプリに使う…」、プロファイルとページの削除は、⌘Z で元に戻せます（⇧⌘Z でやり直し）
- マスを空にしたとき・中身のあるマスを置き換えたとき・プロファイルやページを削除したときは、9マスの下に出る「元に戻す」でも戻せます。その後でまた変えたマスは、元に戻さずにそう知らせます
- 読み込みでの置き換えは ⌘Z では戻せません。代わりに、次の控えから戻します
- Nonet は、設定を変えている間（1時間に1回まで）と、プロファイルやページの削除・読み込み・プリセットに戻す・以前の設定に戻す前に、その時点の設定の控えを `~/Library/Application Support/Nonet/Backups/` に新しいものから10個残します。設定の「Nonet」のタブの「書き出しと読み込み」の「以前の設定に戻す…」で控えを選び、「戻す…」→「この設定に戻す」で、そのときのプロファイルと設定に戻せます。戻す前の設定も控えに残るので、後で戻せます

### 作り込むときの操作

- **プロファイル**: 右クリックの「複製して別のアプリに使う…」で、ページとマスをすべて写した別のアプリのプロファイルを作ります（元のアプリのメニュー項目を押すマスは、新しいアプリのメニューを押します。VS Code から Cursor へ写すときなど）。「プリセットに戻す…」は、確かめてからマスをプリセットの中身に置き換えます
- **マス**: ⌘C / ⌘V でコピーと貼り付け。ほかのプロファイルのマスにも貼れるので、プロファイルの間でマスを写すのにも使えます
- **9マスで使うキー**: ⌘D で複製、⌘⌫ で空にする、⌥⌘＋矢印キーで隣と入れ替え、Return で表示名の欄へ
- **プロファイルのタブで使うキー**: ⌘1〜⌘3 でページを切り替え、⌘F でプロファイルの絞り込み

### インスペクタ

右の列で、選んだマスを設定します。変更はその場で保存されます。

- **空きマス**: アクションの種類のボタンを押して作ります
- **表示名**: マスの下に出る名前です。空のときは、中身から自動で付けた名前を使います
- **アイコン**: 表示名の左のアイコンを押して選びます。「記号」（SF Symbols。英語の名前で検索します）か「アプリ」（「このアプリのアイコンを使う」。アプリを開くマスか、アプリのプロファイルで使えます）。「既定のアイコンに戻す」で元に戻ります
- **アクションの種類**: キー入力・開く・スクリプト・ショートカット・メニュー項目・AI・ファイル（次の「アクションの種類」）
- **少し長く止めてから実行**: オンにすると、HUD でこのマスに指を少し長く止めてから離したときだけ実行します（「基本の使い方」の「[少し長く止めるマス](#少し長く止めるマス)」）
- **このマスをテスト実行**: その場で実行して、「実行しました」かエラーを表示します。スクリプトやショートカットの出力は、その下に出ます（選んでコピーできます）。アプリのプロファイルでは、そのアプリを前面に出してから実行します。グローバルのマスは、設定を開く前に使っていたアプリの前で実行します
- **このマスを空にする**: 中身を消して空きマスに戻します

### メニューから割り当て

ショートカットを調べなくても、アプリのメニューから選んで割り当てられます。

1. 対象のアプリを起動しておきます
2. 9マスの右上の「メニューから割り当て」を押し、ポップアップメニューからアプリを選びます
3. 「メニューを検索」で探し、項目を空いているマスへドラッグします。ダブルクリックか、右クリックの「空いているマスに入れる」でも入ります

インスペクタに戻るときは、パネルの右上の「×」（インスペクタに戻る）を押します。

## アクションの種類

### キー入力

前面のアプリにキーを送ります。「送るキー」の欄（「クリックして記録」）を押してから、送りたいキーをそのまま押すと記録されます。

- `⌘B`、`⇧⌘4` のような組み合わせ
- `⌘L → ⌘C` のような、続けて押すキー（4つまで。40ミリ秒の間隔で送ります）

記録しているとき（欄に「キーを押してください…」と出ている間）は、次のように動きます。

- 続けて押すと連続キーになります。Return や Tab もそのまま記録します
- 「完了」を押すか、ほかの場所をクリックすると決まります。4つ押したときも決まります
- Esc を押すと、何も変えずに記録をやめます（「やめる」も同じ）。Esc キーそのものを送りたいときは「Esc を加える」を押します
- 押し間違えたキーは、⌫（最後のキーを消す）で消せます

⌘Tab・⌘Space やスクリーンショットの ⇧⌘4 のように、macOS が先に使うキーは記録欄に届きません。そのときは、記録欄の下の「表記で入力」の欄にキーを書いて「決定」を押します。`⇧⌘4` のような記号のほか、`cmd+shift+4` のような書き方も読めます。続けて押すキーは `→` か `,` で区切ります。

JIS 配列でも、`⌘[` などが正しく届きます。

スクリーンショットもキー入力のマスで撮れます。プリセットの「範囲を撮影」は、⇧⌘4 を送るだけのキー入力のマスです。

### 開く（アプリ・URL）

アプリか URL を開きます。「開くもの」で「アプリ」か「URL」を選びます。

- **アプリ**: 起動していなければ起動し、起動中なら前面に出します。「開くアプリ」の「アプリを選ぶ…」で、インストール済みのアプリから選びます。一覧にないアプリは「一覧にないアプリを選ぶ…」で選べます。開くアプリの名前は、インスペクタと、マスにポインタを重ねたときのヘルプに出ます。「前面のときは隠す」をオンにすると、もう一度実行したときに隠れるので、アプリの切り替えのように使えます
- **URL**: 「開く URL」を既定のアプリで開きます。`https://` を省いた場合は自動で補います（`localhost` などは `http://`）。`obsidian://` のような、アプリ独自の URL も使えます。`/` や `~` で始めると、ファイルやフォルダとして開きます

### スクリプト

「実行するスクリプト（zsh）」の欄に書いた zsh のスクリプトを実行します（`/bin/zsh -l -c`）。欄の右上の「?」を押すと、下の環境変数の説明が出ます。

- **実行の仕方**
  - 裏で実行: 終わるまで待ちます。「制限時間」（既定 60秒、1〜3600秒）を過ぎると止めます。失敗したら（終了コードが 0 以外）、エラー出力の最後の部分を画面に表示します。0.5秒で終わらないときは、終わるまで画面の下に「「◯◯」を実行中…」と出ます
  - ターミナルで実行: ターミナルの新しいウィンドウで実行します。`claude` のような対話型のコマンドに向いています
- **出力**（裏で実行のときだけ）: スクリプトの標準出力があれば、最後の改行を除いて結果のパネルに出します（AI の「画面に表示」と同じで、文を選んでコピーできます）。出力が空なら何も出しません。64 KB より大きい出力は使わずにエラーにします
- **作業フォルダ**: プロジェクトのフォルダ（下記）。分からなければホームフォルダ
- **環境**: 裏で実行するときはログインシェル（`zsh -l`）で動き、`PATH` はターミナルと同じもの（Nonet の起動時に `~/.zshrc` まで読んで調べたもの）を使います。`~/.zshrc` のエイリアスや関数を使えるのは「ターミナルで実行」のときだけです（ターミナルで実行するときは `~/.zshrc` を読み込みます）。`~/.zshrc` を変えたら Nonet を終了して開き直してください

#### スクリプトに渡す環境変数

実行したときの前面のアプリの情報を渡します。**値がないものは設定されません**。

| 変数 | 中身 | 例 |
|---|---|---|
| `NONET_APP_BUNDLE_ID` | 前面のアプリの bundle ID | `com.apple.dt.Xcode` |
| `NONET_APP_NAME` | 前面のアプリの名前 | `Xcode` |
| `NONET_DOCUMENT_PATH` | 前面のウィンドウで開いている書類（Visual Studio Code・Cursor など、書類の場所を macOS に知らせないアプリでは空） | `/Users/you/dev/App/App.xcodeproj` |
| `NONET_PROJECT_DIR` | 書類から決めたプロジェクトのフォルダ | `/Users/you/dev/App` |
| `PROJECT_DIR` | `NONET_PROJECT_DIR` と同じ | `/Users/you/dev/App` |
| `NONET_BROWSER_URL` | ブラウザで表示中のページ（Safari・Google Chrome・Arc・Microsoft Edge・Brave） | `https://example.com/article` |
| `NONET_SELECTED_TEXT` | 選択中のテキスト | |

選択中のテキスト（`NONET_SELECTED_TEXT`）とブラウザの URL（`NONET_BROWSER_URL`）は、スクリプトにその変数の名前が書かれているときだけ読みます（読むために ⌘C を送ったり、ブラウザに問い合わせたりするため）。名前が書かれていないスクリプトでは、⌘C を送らず、ブラウザにも問い合わせません（オートメーションの確認も出ません）。選択中のテキストを直接読めないアプリでは、⌘C でコピーして読み、クリップボードは元に戻します。別のファイルのスクリプトを呼ぶだけのときは、コメントでよいので、使う変数の名前を書いておいてください（下の例）。ほかの変数（`NONET_APP_BUNDLE_ID`・`NONET_APP_NAME`・`NONET_DOCUMENT_PATH`・`NONET_PROJECT_DIR`・`PROJECT_DIR`）は、値があればいつも設定します。

Visual Studio Code と Cursor は、開いている書類の場所を macOS に知らせません（ウインドウの題名も「Code」だけです）。そのため、これらのアプリの前では `NONET_DOCUMENT_PATH` と `PROJECT_DIR` が空になり、プリセットの Claude Code のマスはホームフォルダで開きます。プロジェクトのフォルダで開きたいときは、スクリプトの `cd "${PROJECT_DIR:-$HOME}"` をそのフォルダの場所に書き換えてください。

プロジェクトのフォルダは次のように決めます。

- 書類が `.xcodeproj`・`.xcworkspace`・`.swiftpm` なら、その入っているフォルダ
- ほかのファイルなら、上へたどって `.git` か `Package.swift` のあるフォルダ。見つからなければ、そのファイルのあるフォルダ
  - ホームフォルダの中では、ホームフォルダの手前までたどります（何段でもたどるので、Maven・Gradle・Android のような深いフォルダでも見つかります）
  - ホームフォルダの外（`/Volumes/SSD` など）では、書類から上へ32個のフォルダまでです。`/` や `/Volumes` のような、いちばん上のフォルダは調べません
  - ネットワーク上の場所の書類では探さず、そのファイルのあるフォルダを使います
  - 0.3秒のうちに調べ終わらないとき（眠っている NAS など）は、プロジェクトのフォルダはなしになり、スクリプトはホームフォルダで動きます

例:

```zsh
# Claude Code をプロジェクトのフォルダで開く（「ターミナルで実行」）
cd "$PROJECT_DIR" && claude

# プロジェクトを VS Code で開く
open -a "Visual Studio Code" "${PROJECT_DIR:-$HOME}"

# 表示中のページの URL をクリップボードへ
printf '%s' "${NONET_BROWSER_URL:?ブラウザが前面にありません}" | pbcopy

# 選択中のテキストを別のファイルのスクリプトに渡す（このコメントに NONET_SELECTED_TEXT と書いてあるので読みます）
~/bin/translate.sh
```

変数は必ず `"$NONET_SELECTED_TEXT"` のように `"` で囲んでください（空白や記号を含むことがあります）。ないかもしれない変数は `${変数:-既定値}` か `${変数:?メッセージ}` で扱うと安全です。`:?` のメッセージは失敗として画面に出ます。

### ショートカット

ショートカット.app のショートカットを実行します。「実行するショートカット」に名前を入れるか、横の一覧のボタン（ショートカットの一覧から選ぶ）から選びます。「選択中のテキストを渡す」をオンにすると、選択中のテキストを入力として渡します。

ショートカットがテキストを返したときは、最後の改行を除いて結果のパネルに出します。何も返さなければ、何も出しません。

### メニュー項目

アプリのメニュー項目を押します。「メニューから割り当て」で選ぶのがかんたんです（インスペクタの「メニューから選ぶ…」でも開きます）。「押すメニュー項目」に、項目の場所・アプリ・キーが出ます。

- 対象のアプリが前面にあり、その項目のキー（ショートカット）が、アプリのメニューにあるその項目のキーと同じなら、キーを送ります（速い）。同じでないとき（アプリのアップデートでキーが変わった・メニューを読めない など）は、メニューを順にたどって押します
- キーがなければ（「なし（メニューを順にたどって押します）」）、アクセシビリティの機能でメニューを順にたどって押します
- 「再生」⇄「一時停止」や「ツールバーを表示」⇄「ツールバーを非表示」のように、押すと名前が変わる項目も、続けて使えます。名前が見つからなければ対になる名前で探し、それでもなければ、同じメニューに同じキー（ショートカット）の項目が1つだけならそれを押します
- 対象のアプリが起動している必要があります
- メニューの名前は macOS の言語で変わります。言語を変えたら割り当て直してください

### AI

選択中のテキストと「指示文」を、Mac の中の言語モデル（Apple Intelligence）に渡します。テキストが Mac の外に送られることはありません。

- 必要なもの: macOS 26 以降、Apple Intelligence に対応した Mac、**システム設定 › Apple Intelligence と Siri** で Apple Intelligence をオン（モデルのダウンロードが終わっていること）
- 結果の出し方:
  - 選択範囲を置き換える: 選択中のテキストを結果で置き換えます（クリップボードを通して ⌘V で貼り付け、クリップボードは元に戻します）。待っている間に前面のアプリが変わったときは、代わりにクリップボードにコピーします。アプリが選択範囲を知らせず ⌘C で読んだとき（貼り付けると、カーソルの位置に入ってしまうことがあるため）と、クリップボードの中身を元に戻せないとき（下の「[選択中のテキストを読めない](#選択中のテキストを読めない)」）は、貼り付けずに結果のパネルに出します
  - クリップボードにコピー
  - 画面に表示: 結果のパネルに出します。文を選んでコピーすることもできます。「コピー」で結果をコピーし、「閉じる」か Esc でパネルを閉じます
- 使えない Mac では、インスペクタと実行したときに理由を表示します
- 0.5秒で終わらないときは、終わるまで画面の下に「「◯◯」を実行中…」と出ます
- クリップボードを元に戻すとき、コピーしてあった画像は1つの形式だけを、Finder でコピーしたファイルはファイルだけを（アイコンの絵は除いて）戻します

### ファイル

Finder で選んでいるファイルを、ゴミ箱に入れる・名前を変更・複製します。Finder でファイルをクリックして選び、9マスを開いてこのマスを選ぶと、そのファイルにすぐ使えます。

- **操作**:
  - ゴミ箱に入れる: Finder の「ゴミ箱に入れる」と同じです。完全には削除しないので、ゴミ箱から戻せます。ゴミ箱の中のファイルと、ネットワーク上のファイルなどゴミ箱の無い場所のファイルは動かしません。新しく作るときは「少し長く止めてから実行」が自動でオンになります（外せます）
  - 名前を変更: Finder の名前の変更（Return を押したときと同じ）を始めます。名前を入力して Return で決めます。1つだけ選んでいるときに使えます
  - 複製: 同じ場所に「◯◯のコピー」を作ります。大きなファイルは時間が掛かります（Finder に頼んで、最長10分待ちます）
- **対象**: Finder が前面にあるとき、Finder で選んでいるファイルです（デスクトップのアイコンも含みます）。実行する直前の前面のアプリで確かめるので、別のアプリが前面のときは、裏の Finder のウインドウで選んだままのファイルを動かさないよう、何もせずにエラーを表示します。何も選んでいないときも同じです。シンボリックリンクは、リンク先を動かしてしまうので動かしません。選んでいるファイルが500個を超えるとき、ホームフォルダ・ホームの標準のフォルダ（デスクトップ・書類など）・ディスクの一番上・システムのフォルダ・ほかの利用者のホームが含まれるときは、何もしません
- **許可**: 初めて使うときに、macOS が「Nonet が Finder を操作しようとしています」と確かめます（「困ったとき」の「[オートメーションの許可を求められた](#オートメーションの許可を求められた)」）。Nonet が読むのは、Finder で選んでいるファイルの場所だけで、ファイルの中身は読みません
- 設定の「このマスをテスト実行」は、実行する前に確かめます（設定の画面からは、Finder で何を選んでいるか見えないため）
- Finder のプリセットの2ページ目（「選んだファイル」）に、複製・名前を変更・ゴミ箱に入れる（少し長く止めてから実行）が入っています

### 開き方と HUD

### 書き出しと読み込み

「Nonet」のタブの「書き出しと読み込み」で、プロファイルを `.nonetprofile` のファイルに書き出して、バックアップしたり、別の Mac やほかの人と共有したりできます。書き出すのはプロファイル（9マスの中身）だけで、一般の設定やライセンスは含みません。

- **書き出す…**: すべてのプロファイルを1つのファイルに書き出します。1つだけ書き出すときは、プロファイルの一覧で右クリックして「このプロファイルを書き出す…」を選びます
- **読み込む…**: ファイルのプロファイルを加えます（20MB を超えるファイルは読み込めません）。次のどちらかに当たるときは、先に「「ファイル名」を読み込みますか？」と確かめます
  - 今の設定が置き換わる（ファイルにグローバルが入っている、または同じアプリのプロファイルがすでにある）: 置き換わるものを並べます
  - 何かを実行するマスがある（スクリプト・キー入力・メニュー項目・AI・ショートカット.app のショートカット・Finder で選んだファイルをゴミ箱に入れる、名前を変える、複製するファイルのマスと、Mac の中のファイルを開く URL、別のものを動かす URL（ショートカットの実行・ssh・共有フォルダなど））: 何も置き換わらなくても確かめます。マスごとに「プロファイル › マス」と中身のすべてを、スクロールできる欄に切らずに並べます。スクリプトはすべての行、キー入力は押すキーのすべて、メニュー項目は場所とショートカット、AI は指示と結果の出し方、ショートカットは名前、ファイルは操作、URL は開く場所です。見えない文字は「⟨U+202E⟩」のような形で見せます
- **以前の設定に戻す…**: 削除や読み込みの前などに残した控えから、以前の設定に戻します（「プロファイルを編集する」の「元に戻す・以前の設定に戻す」）

中身の欄では、Return と同じ働きのキー（または ⌃ の付いたキー）を押すマスと、注意が要る命令（curl・wget・base64・eval・`| sh`（bash や zsh も）・osascript・rm -rf）を含む行に、橙色の印と説明が付きます。何かを実行するマスがあるときは、欄を最後までスクロールするまで「読み込む」「置き換えて読み込む」「新しいプロファイルだけ追加」を押せません（「最後までスクロールして中身をすべて確かめると、読み込めます」と出ます）。

確かめるときは、中身を見て次のどれかを選びます。

- 置き換えて読み込む: 置き換わるものがあるときに出ます。一覧のものをファイルの中身で置き換え、新しいアプリのプロファイルも加えます。⌘Z では戻せませんが、読み込む前の設定は「以前の設定に戻す…」に残ります
- 読み込む: 置き換わるものがないときに出ます。ファイルのプロファイルを加えます
- 新しいプロファイルだけ追加: 今のプロファイルには触れず、まだないアプリのプロファイルだけ加えます（置き換わるものと、加えるものの両方があるときだけ出ます）
- キャンセル: 何も変えません

どちらにも当たらなければ、確かめずにそのまま加えます。結果（追加した数・置き換えた数・読み込まなかった数）は、ウィンドウの上の帯に出ます。メニュー項目のマスのキー（ショートカット）は1つのキーだけを読み込みます。それより長いものは捨て、その項目はメニューを順にたどって押します。1つのキーでも、アプリのメニューにあるその項目のキーと違えば、実行するときはメニューを押します（「アクションの種類」の「メニュー項目」）。

**ほかの人から受け取ったプロファイルは、信頼できるものだけを読み込んでください**（スクリプトやキー入力はあなたの権限で動きます）。読み込む前の確認で、マスの中身をすべて確かめてください。スクリプトを含むときは、読み込んだ後の帯でも知らせます。

## 試用とライセンス

- 初めて起動した日から**14日間**、すべての機能を無料で使えます。残り日数は Nonet のメニューと、設定の「Nonet」のタブに出ます
- 残りが3日以下になると、アイコンに「!」が付き、メニューのいちばん上の行に残り日数が出ます。HUD の上にも「試用期間は残り3日です」のように1日に1回出ます。Nonet のメニューの「Nonet を購入…」「ライセンスキーを入力…」から、いつでも購入・登録できます
- 試用期間が終わると、上の縁から指を滑らせても9マスは開かず、画面の下に「試用期間が終了しました」「メニューバーの Nonet から購入・登録できます」と出ます（軽く2回振動します）。設定はそのまま残ります。小さなウィンドウ「Nonet の試用期間が終了しました」（1日に1回まで。「購入する」「ライセンスキーを登録…」「あとで」）と、設定のウィンドウの上の帯（「購入する」「ライセンスキーを入力…」）からも購入・登録できます
- 購入すると、ライセンスキーがメールで届きます。1つのライセンスで、あなたが使うすべての Mac に使えます。購入から30日以内なら全額を返金します
- 返金したライセンスのキーと、公開されてしまったキーは、その後に出る版の Nonet では使えません。登録していたキーが使えなくなったときは、「Nonet」のタブに理由が出て、試用期間が残っていれば試用に戻ります

設定の「Nonet」のタブのライセンスの欄:

- **状態**: 「試用期間中（残り14日・11月14日まで）」「登録済み」「試用期間が終了しました」のどれかです。登録済みなら、登録者・発行日・ライセンス ID も出ます
- **買い切りのライセンス**: 「購入する」で購入ページを開きます（登録していないときだけ出ます）
- **購入済みの方**: 購入時のメールに書かれたライセンスキーを欄に貼り付けて「登録」を押すと、すぐに使えるようになります。「License key:」のような前後の文字ごと貼り付けても、キーの部分だけを読みます。キーはこの Mac の中で確かめるので、ネットワークもアカウントも要りません。登録できないときは理由と次にすることが出ます（その横の「お問い合わせ…」で問い合わせのメールを作れます）。キーが見つからないときは「ライセンスキーが見つからないときは」から。購入のメールの「Nonet に登録する」のリンクや、添付の `.nonetlicense` のファイルを開くと、キーが入った状態で「このライセンスキーを登録しますか？」と尋ねます（尋ねずに登録することはありません）
- **ライセンスキー**: 登録済みのとき、「キーをコピー」でキーをコピーして、ほかの Mac にも登録できます。「別のキーを登録…」で別のキーに替えられます
- **この Mac から登録を消す**: 「登録を消す…」を押し、確かめてから「登録を消す」を押すと、この Mac からライセンスキーを消します。Mac を手放すときなどに使います。同じキーは、ほかの Mac でもそのまま使えます

## アップデートと情報

新しい版は自動で確認されます。見つかると、メニューバーのアイコンの右上のマスが点に変わり、Nonet のメニューの「アップデートを確認」が「アップデートがあります…」に変わります。選ぶと、新しい版の知らせが出ます（起動した直後に見つかったときは、すぐに知らせが出ます）。Nonet のメニューの「アップデートを確認」で、いつでも確認できます。

設定の「Nonet」のタブには、ライセンスの欄と「書き出しと読み込み」の下に、バージョン・「アップデートを確認」・「利用ガイド」（このガイド）・「プライバシー」（プライバシーポリシー）・「お問い合わせ…」・「Nonet をアンインストール…」と、Nonet が使っているサードパーティのソフトウェアのライセンスがあります。Nonet を英語で使っているときは、利用ガイドとプライバシーポリシーは英語のページが開きます。

「お問い合わせ…」を押すと、メールのアプリで問い合わせのメールが開きます。本文に入るのは、Nonet と macOS の版・Mac の機種・キーボードの種類だけです（ライセンスキーや設定の中身は入りません）。送るかどうかは、あなたが決めます。

## 困ったとき

Nonet が動けないときは、Nonet のメニューのいちばん上の行と、設定のウィンドウの上の帯に理由が出ます。

### 「アクセシビリティの許可が必要です」と出る

- 設定のウィンドウの上の帯の「システム設定を開く」（最初は macOS の確認が出ます。もう一度押すとシステム設定が開きます）か、Nonet のメニューの「アクセシビリティを許可…」を押します
- **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet をオンにします。許可されると自動で動き出します
- オンになっているのに効かないとき（アップデートの後など）は、一覧から Nonet を選んで「−」で外し、もう一度追加してオンにしてください

### 「パスワードの入力中は動きません」と出る

パスワード欄にカーソルがあるときや、ターミナルの「セキュアキーボード入力」がオンのとき、macOS はほかのアプリにキーを見せないので、Nonet は9マスを開きません。パスワード欄から離れるか、ターミナル › セキュアキーボード入力 をオフにしてください。離れると自動で戻ります。帯の「もう一度確かめる」ですぐに確かめ直せます。

### 「トラックパッドが見つかりません」と出る

MacBook の内蔵トラックパッドか Magic Trackpad が必要です。マウスだけでは使えません。Magic Trackpad をつないだり、つなぎ直したりしたときは、Nonet が自動で見つけ直します（10秒ほどかかることがあります）。帯の「もう一度確かめる」で、すぐに確かめ直すこともできます。それでも反応しないときは、Nonet のメニューの「終了」で Nonet を終了し、もう一度起動してください。

### まったく反応しない

- Nonet のメニューの「Nonet を有効にする」にチェックが付いているか確かめます
- 前面のアプリで「このアプリでは使わない」にチェックが付いていないか確かめます（プロファイルの一覧で「オフ」の印が付いたアプリです）
- 試用期間が終わっていないか確かめます（Nonet のメニューに「試用期間が終了しました」と出ます）
- 上の3つ（アクセシビリティ・パスワードの入力中・トラックパッド）のどれかが出ていないか確かめます
- トラックパッドの上の縁（奥の端）に指を置いてから、すっと下へ滑らせているか確かめます。縁より手前から始めたときや、触れてから 0.6 秒以上たって動かし始めたときは開きません（設定の「開きやすさ」を「開きやすい」にすると、縁から 13mm ほど・1秒まで受け付けます）。奥の端の近くから下へポインタを動かすと、速さによらず開きます（「基本の使い方」の「[開く](#開く)」）
- 設定のウィンドウなど、Nonet のウィンドウが前面にあるときは、上の縁から指を滑らせても9マスは開きません（設定では、マスのドラッグなどにトラックパッドを使うため）。先に使いたいアプリに切り替えるか、設定の中で試すときは、インスペクタの「このマスをテスト実行」を使います。設定のウィンドウを閉じると、その前に使っていたアプリが前面に戻ります

### メニューバーにアイコンが見えない

メニューバーに項目が多いと、Nonet のアイコンが隠れることがあります。アプリケーションフォルダから Nonet をもう一度開くと、すぐに設定のウィンドウが開きます。

### 開くつもりがないのに開く

ポインタを動かそうとして、トラックパッドの奥の端から指をすばやく下へ動かすと、9マスが開きます。開いてしまったら、そのまま指を離せば何も実行しません（開いた瞬間の指は外枠にいます）。よく起きるときは、ポインタを動かすときに、奥の端から少し離れたところに指を置いてください。Nonet を使わないアプリでは、Nonet のメニューの「このアプリでは使わない」を選んでおくと開かなくなります。

### ポインタが動かない・クリックが効かない

9マスを開いている間は、ポインタとクリックを止めています。開いたままと判断されているときは、次のどれかで戻ります。

- トラックパッドから指をすべて離す
- 何かキーを押す（その場で閉じます）
- マウスを動かすかクリックする（その操作はそのままアプリに届きます）
- 20秒待つ（長すぎる操作は自動で終わります）
- それでも戻らなければ、Nonet のメニューの「終了」

### 狙ったマスと違うものが実行される

マスはトラックパッドの**絶対的な位置**で決まります。HUD で光っているマスを確かめてから離してください。狙いと違うマスが光っていたら、指を滑らせて選び直すか、外枠まで滑らせて離せば何も実行しません。マスとマスの境目の線の上では実行しないので、マスの中ほどで離します。取り消せない操作のマスは、「少し長く止めてから実行」にしておくと安心です（「基本の使い方」の「[少し長く止めるマス](#少し長く止めるマス)」）。メニューの「最近の実行」で、何が実行されたかを確かめられます。

### スクリプトが失敗する

- 画面に出たエラーを確かめます。終了コード 127（`command not found`）なら、ターミナルで `command -v <名前>` を実行して、インストールされているかを確かめてください。裏で動くスクリプトはターミナルと同じ `PATH` を使います（Nonet の起動時に調べるので、`~/.zshrc` を変えたら Nonet を開き直してください）
- ターミナルで `zsh -lic '<スクリプト>'` を実行すると、近い条件で試せます
- インスペクタの「このマスをテスト実行」で、結果をその場で確かめられます
- 時間がかかる処理は、「制限時間」を延ばすか「ターミナルで実行」にしてください

### オートメーションの許可を求められた

スクリプトに `NONET_BROWSER_URL` が書かれていて、対応しているブラウザ（Safari・Google Chrome・Arc・Microsoft Edge・Brave）が前面にあるとき、Nonet は実行の直前に、そのブラウザに表示中のページの URL を問い合わせます。初めてのときに macOS が、Nonet にそのブラウザの操作を許可するか確かめます。URL を使うなら許可して、もう一度実行してください。許可しなくても、スクリプトは `NONET_BROWSER_URL` がないまま実行されます。

ファイルのアクションを初めて使うときは、Nonet に Finder の操作を許可するか確かめます。Finder で選んでいるファイルを読み、ゴミ箱に入れる・名前を変更・複製をするために使います。許可しなければ、ファイルのマスは「オートメーション（Finder）の許可が必要です」と表示して何もしません。

拒否した後に使いたくなったら、**システム設定 › プライバシーとセキュリティ › オートメーション** で、Nonet の下のブラウザや Finder をオンにします。

### メニュー項目のアクションが失敗する

- 対象のアプリが起動しているか確かめます
- アプリのアップデートや macOS の言語の変更で、メニューの名前が変わっていないか確かめます。変わっていたら「メニューから割り当て」で割り当て直してください

### AI のアクションが使えない

macOS 26 以降か、Apple Intelligence がオンでモデルのダウンロードが終わっているか、Mac が Apple Intelligence に対応しているかを確かめてください。理由はインスペクタの AI の欄にも出ます。テキストを選んでから実行してください。

### 選択中のテキストを読めない

AI・ショートカット・スクリプトに選択中のテキストを渡すとき、アプリが選択範囲を直接知らせなければ、Nonet は ⌘C でコピーして読み、クリップボードを元に戻します。AI のアクションで読めなかったときは、理由に合わせて次のように出ます（ショートカットとスクリプトには、選択中のテキストを渡さずに実行します）。

- 「テキストを選択してから実行してください」: テキストを選んでから、もう一度実行します。VS Code・Cursor・Obsidian・JetBrains の IDE・Sublime Text では、何も選んでいないと ⌘C で行が丸ごとコピーされるので、改行で終わる1行だけが取れたときは選択なしとみなします（「1行だけを使うときは、行末の改行を含めずに選択してください。」と出ます）
- 「クリップボードの中身を保てないため、選択テキストを読めませんでした。…」: 元に戻せないものがクリップボードにあるので、⌘C を送りませんでした（64 MB より大きい、貼り付けたときに作られるファイル、コピーした元のアプリが時間内に中身を渡さない など）。選んだテキストを自分で ⌘C でコピーしてから、もう一度実行します
- 「Nonet がクリップボードを読むことが許可されていないため、選択テキストを読めませんでした。…」: macOS がクリップボードを読ませない設定になっています（下）。**システム設定 › プライバシーとセキュリティ** で Nonet に許可します

macOS 15.4 以降で、クリップボードを読む前に確かめる設定のときは、Nonet がクリップボードを読もうとすると、macOS がほかのアプリからのペーストを許可するか確かめることがあります。20秒のうちに答えてください。いつも拒否する設定なら、Nonet はクリップボードを読みも戻しもしません。⌘C で選択中のテキストを読むことはせず、「選択範囲を置き換える」は結果のパネルに出します。

- パスワード管理アプリでコピーしたパスワードは、読みも戻しもしません
- ⌘C を送っても何もコピーされなかったときは、遅れてコピーするアプリのために0.5秒だけ待ちます。その間にコピーされたものは、そのアプリがまだ前面にあるときだけ元に戻します。その後にあなたが自分でしたコピーを戻すことはありません

### 振動しない

設定の「触覚」がオフになっていないか確かめます。振動は感圧タッチ（Force Touch）のトラックパッドでだけ感じられます。

### ログイン時に起動しない

「ログイン時に起動」をオンにしたとき、macOS の確認が要ることがあります。**システム設定 › 一般 › ログイン項目**（macOS 15 以降は「ログイン項目と機能拡張」）で Nonet を許可してください。

### 「設定ファイルが壊れていたため読み込めませんでした」と出る

設定のファイルが壊れていたので、最初の設定で始めました。元のファイルは、知らせに出た名前で同じフォルダ（`~/Library/Application Support/Nonet/`）に残っています。「以前の設定に戻す…」に控えがあれば、そこから戻せます。書き出しておいたファイルがあれば、「読み込む…」でも戻せます。知らせは Nonet のメニューの「この知らせを消す」で消せます。

### 設定を最初に戻したい

Nonet を終了してから `~/Library/Application Support/Nonet/` をゴミ箱に入れ、もう一度起動すると、初回の状態から始まります。試用期間の残り日数とライセンスの登録は、そのまま残ります。少し前の設定に戻したいだけなら、「以前の設定に戻す…」を使います。

## アンインストール

1. 設定の「Nonet」のタブで「Nonet をアンインストール…」を押し、「アンインストール」を押します。ログイン時の起動を止め、Nonet 本体と設定のフォルダ（`~/Library/Application Support/Nonet/`）とキャッシュをゴミ箱に入れます。ライセンスキーと試用の記録は残るので、入れ直せば登録し直さずに使え、試用期間もやり直しにはなりません。ゴミ箱を空にするまでは元に戻せます
2. 「システム設定を開いて終了」を押すと、システム設定が開いて Nonet が終わります。**プライバシーとセキュリティ › アクセシビリティ** の一覧で Nonet を選び、「−」で外します。ターミナルで `tccutil reset Accessibility com.iam74k4.Nonet` を実行しても同じです

Nonet 本体をゴミ箱に入れられなかったときは、何も変えずに知らせます。Nonet を終了してから、Finder でアプリケーションフォルダの Nonet をゴミ箱に入れてください。

ライセンスキーと試用の記録まで消すときは、Nonet を終了してから次のものも消します。

- `~/Library/Preferences/com.iam74k4.Nonet.plist`（試用の記録・ライセンスキーなどの環境設定）
- キーチェーンアクセスで `com.iam74k4.Nonet.license.trial` を検索し、見つかった項目（試用の記録）
- キーチェーンアクセスで、名前が64桁の16進数（0〜9 と a〜f）の項目（同じ試用の記録の写し。名前はこの Mac とアプリから作ったもので、Nonet の名前は付いていません）

ライセンスを別の Mac で使うなら、消す前にライセンスキーを控えておきます（設定の「Nonet」のタブの「キーをコピー」）。
