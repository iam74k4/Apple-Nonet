## Nonet とは

トラックパッドを強く押し込んで少し止めると、MacBook のトラックパッドが「アプリごとに変わる 3×3 の9つのボタン」になるアプリです。操作はトラックパッドだけで済み、キーは使いません。

- トラックパッドのどこかを強く押し込んで（2回目のカチッまで）少し止めると、ポインタの周りに9つのアイコン（HUD）が開きます。力を抜いて指を滑らせてポインタをアイコンへ向け、離すと実行します
- 真ん中から見た**ポインタの向き**でマスが決まります。8つの向きと真ん中で、設定の 3×3 の9マスにあたります
- 迷ったら、アイコンの輪の外まで動かして離せば、何も実行せずに閉じます
- 前面のアプリに合わせて9マスが切り替わります。1つのプロファイルに最大3ページ（27マス）まで置けます

### 動作環境

- macOS 14 Sonoma 以降（Apple シリコン・Intel）
- マルチタッチのトラックパッド: MacBook の内蔵トラックパッド、または Magic Trackpad。マウスだけの Mac では使えません
- AI のアクションだけは、macOS 26 以降で Apple Intelligence が使える Mac が必要です

## はじめに

### インストール

1. ダウンロードした `Nonet-<バージョン>.dmg` を開きます
2. `Nonet` を `Applications` フォルダへドラッグします
3. アプリケーションフォルダから Nonet を開きます

ディスクイメージの中やダウンロードしたままの場所から開くと、そこからはアップデートを入れられないため、「Nonet をアプリケーションフォルダに移しますか？」と確かめます。「アプリケーションフォルダに移す」を押すと、移してから開き直します（管理者でないアカウントでは、ホームフォルダの中の「アプリケーション」に移します）。アプリケーションフォルダにすでに Nonet があるときは、置き換えてよいかをもう一度確かめ、前の Nonet はゴミ箱に入れます。どちらのフォルダにも移せないときは、Finder で移す方法を案内します。

Nonet はメニューバーに常駐するアプリで、Dock には出ません。メニューバーの、点が輪に並んだアイコン（真ん中にも点）が Nonet です。このガイドでは、このアイコンを押すと開くメニューを「Nonet のメニュー」と呼びます。

Nonet は同時に1つしか動きません。動いているときにもう一度開くと、新しく起動する代わりに、動いている Nonet の設定のウィンドウがすぐに開きます。終了した直後に開いたときは、前の Nonet が終わるのを待ってから起動します。ディスクイメージから開いた Nonet とアプリケーションフォルダの Nonet が重なったときは、アプリケーションフォルダの方が動きます。ただし、ディスクイメージの方が新しい版なら、そちらが動きます（アプリケーションフォルダの Nonet が動いていれば終わらせてから起動し、「Nonet をアプリケーションフォルダに移しますか？」と確かめます）。ディスクイメージの方が新しくないときは、「Nonet はすでに動いています」と知らせて終わり、動いている Nonet の設定のウィンドウが開きます。

### アクセシビリティの許可

初めて起動すると「Nonet へようこそ」のウィンドウ（初回の案内）が開きます。「システム設定を開く」を押すと macOS の確認が出るので、そこから **システム設定 › プライバシーとセキュリティ › アクセシビリティ** を開き、Nonet をオンにしてください（パスワードか Touch ID を求められます）。確認が出ないときや、もう一度押したときは、システム設定のその欄が開きます。許可すると、システム設定の後ろに隠れた案内のウィンドウが自動で前に戻り、次へ進みます。

**なぜ必要か**: macOS では、ほかのアプリを使っている間のポインタやキーボードを扱うのにこの許可が要ります。Nonet は次のことにだけ使います。

- トラックパッドを強く押し込んで止めたかが分かるまで、そのクリックを預かる（強く押し込んで止めなければ、すぐにそのまま渡す）
- 9マスを開いている間、ポインタの移動とクリックを前面のアプリに渡さない
- 9マスを開いている間に、キーが押されたことを知る（何も実行せずに閉じるため）。9マスを開いていない間は、キーボードを見ません
- 設定したキー入力を送る・メニュー項目を押す・選択中のテキストを読む

**集めないもの**: 入力した文字の内容は記録も送信もしません。設定は Mac の中（`~/Library/Application Support/Nonet/`）だけに保存し、アカウントもありません。ネットワークを使うのは、アップデートの確認と購入ページを開くときだけです。トラックパッドの指の位置を読むのに許可は要りません。詳しくは[プライバシーポリシー](privacy.md)をご覧ください。

「あとで許可する」で先へ進むこともできますが、許可するまで Nonet は動きません（案内の上に並んだ段階の「アクセシビリティ」に「!」が付きます）。許可しないままトラックパッドを強く押し込んでも、ふつうのクリックになるだけで、9マスは開きません。許可しないまま終えると、次に起動したときに「Nonet を使うには、あと1つ許可が必要です」の画面が開きます。「今後表示しない」を選ぶと、もう開きません。あとから許可するときは、Nonet のメニューの「アクセシビリティを許可…」（この画面が開きます）か、設定のウィンドウの上に出る帯の「システム設定を開く」を使います。トラックパッドが見つからないときは、この画面でも知らせ、「もう一度確かめる」で探し直せます。

ファイルのアクションを初めて使うときと、スクリプトでブラウザの表示中のページの URL（`NONET_BROWSER_URL`）を使うときは、macOS が初回に「オートメーション」の許可を求めます（「困ったとき」の「[オートメーションの許可を求められた](#オートメーションの許可を求められた)」）。

### 初回の案内

「Nonet へようこそ」のウィンドウは、上に並んだ2つの段階で進みます。

1. **アクセシビリティ**: 上の許可です
2. **試してみる**: 練習モードで2つ試します。図には、いま HUD に出るマスの名前が並びます。1つ目は「開いて、マスで離す」: トラックパッドに指を置いて強く押し込み、少し止めて HUD が開いたら、力を抜いて案内のマスまで指を滑らせ、そこで離します（違うマスで離したときは、案内のマスがどこにあるかを教えます）。2つ目は「輪の外で離して、やめる」: もう一度強く押し込んで開き、今度はポインタをアイコンの輪の外まで動かしてから離します。練習中は何も実行されません。練習になるのは案内のウィンドウを使っている間だけで、ほかのアプリをクリックすると、マスは本当に実行されます。「スキップ」で飛ばせます。試せないときは、理由と直すためのボタンが出ます。Nonet が無効なら「Nonet を有効にする」、トラックパッドがなければ「もう一度確かめる」、いま使うページのマスがすべて空いていれば「設定を開く」、試用期間が終わっていれば「ライセンスキーを入力…」（ライセンスキーを登録すると、この知らせは消えます）

練習の画面の下には「Mac にログインしたら Nonet を自動で起動する」のチェックボックスと、「戻る」「設定を開く」、2つとも済めば「完了」（済んでいなければ「スキップ」）があります。チェックボックスは、初めて起動したときは入っていて、案内をもう一度見るときは今の設定（設定の「ログイン時に起動」）から始まります。選んだものは、練習の画面から案内を閉じたとき（「完了」「スキップ」「設定を開く」、ウィンドウの閉じるボタン）に反映します。macOS の許可が要るときは、システム設定の「ログイン項目」が開き、練習の画面に「システム設定の「ログイン項目」で Nonet を許可すると、ログイン時に起動するようになります」と出て、案内は開いたままです（もう一度押すと閉じます）。メニューバーに Nonet のアイコンが見えないときは、練習の画面に「メニューバーにアイコンが見えないときは、アプリケーションフォルダから Nonet を開くと設定が開きます」と出ます。

「完了」「スキップ」かウィンドウの閉じるボタンで閉じると、メニューバーの Nonet のアイコンが光り、その下に「Nonet はここにいます」と出ます。「設定を開く」を押すと、そのまま設定のウィンドウが開きます。

最初の設定には、Mac に入っているアプリのうち、プリセット（最初から用意した9マス）のあるもののプロファイルがすべて入っています（Finder・Safari・Chrome・Arc・メール・Outlook・Zoom・Teams・Slack・Excel・Word・PowerPoint・Keynote・Pages・Numbers・Notion・メモ・Obsidian・Figma・Photoshop・Final Cut Pro・Xcode・Visual Studio Code・Cursor・ターミナル）。要らないプロファイルは、設定の「プロファイル」のタブで削除します。Apple Intelligence を使えない Mac では AI のマスを、`claude` コマンドのない Mac では Claude Code のマスを入れず、中央には代わりのマスを置きます。AI のマスの代わりに中央へ移したマスの元の位置には、別のマスが入るので9マスのままです。Claude Code のマスの場所は空きマスになります（Claude Code のマスは、どのプリセットでも中央には置きません）。

グローバルのプロファイルには、Mac にあるよく使うアプリを並べたランチャーが入ります（「基本の使い方」の「[グローバルとランチャー](#グローバルとランチャー)」）。

案内は Nonet のメニューの「初回の案内をもう一度」で何度でも見られます。

## 基本の使い方

### 開く

1. トラックパッドのどこかに指を1本置きます（HUD は、そのときのポインタの周りに出ます）
2. 強く押し込みます。ふつうのクリック（1回目のカチッ）より深く、2回目のカチッと感じるところまで押し込みます（macOS の「強めのクリック」）
3. そのまま少し（標準では 0.25秒ほど）止めます

9マスが開いて、ポインタの周りに HUD（9つのアイコン。8つが輪になって並び、真ん中に9つ目。皿も枠も文字もありません）が出て、トラックパッドが軽く振動します。開いたら力を抜いてかまいません（指はトラックパッドに置いたまま）。ポインタは真ん中にあり、開いている間もふだんどおり動きます。ポインタを向けた先のアイコンの下に白い円が出るので、そのまま指を滑らせてポインタをアイコンへ向け、離すと実行します。開いた瞬間は、ポインタが真ん中にあっても「離すとやめる」の状態で、ここで離せば何も実行せずに閉じます。そこから指を滑らせてポインタをアイコンのほうへ動かすと、選び始めます。真ん中のアイコンは、一度外へ出てから真ん中へ戻すと選べます。

- 強く押し込んで止めている間、そのクリックは前面のアプリに届きません。開いたときはそのクリックを捨てるので、ポインタの下のボタンやリンクは押されません
- 強く押し込まずに離したとき（ふつうのクリック）・押したまま動かしたとき（ドラッグ）・強く押し込まないまま 0.6秒押し続けたとき（押したままで出るメニューなど）は、そのクリックをそのまま前面のアプリに渡します。ふつうのクリックは、アプリに届くのが「押したとき」から「離したとき」に変わりますが、ほとんど気になりません
- 止める時間は、設定の「開きやすさ」で変えられます（控えめ 0.5秒・標準 0.25秒・開きやすい 0.1秒）
- 感圧タッチ（Force Touch）のトラックパッドが要ります（2015年以降の MacBook の内蔵トラックパッドと、Magic Trackpad 2 以降）。macOS の「強めのクリックと触覚フィードバック」（**システム設定 › トラックパッド**）がオフだと、2回目のカチッが無いので開きません（設定の「一般」に知らせが出ます）
- **上の縁から滑らせて開くこともできます**: 設定の「一般」の「開き方」を「上の縁から滑らせる」か「両方」にすると、トラックパッドの上の縁（奥の端）に指を1本置いて、すっと下へ滑らせても開きます。感圧タッチでないトラックパッドや、強く押すのがつらいときに使います。「上の縁から滑らせる」だけにすると、クリックは預かりません
- 「調べる＆データ検出」を「強めのクリック」にしていると、強く押し込んだときは Nonet が先に受け取るので、調べる（辞書やプレビュー）は出ません。調べるも使うときは、**システム設定 › トラックパッド** で「3本指でタップ」に変えてください
- マウスのクリック・指を離した後に届く「タップでクリック」・副ボタンのクリック（2本指のクリック）は預からず、そのまま渡します
- 「このアプリでは使わない」にしたアプリが前面の間と、設定でキーを記録している間は、クリックを預からず、強く押し込んでもふつうのクリックになります
- 設定や初回の案内など、Nonet のウィンドウが前面にあるときは開きません（初回の案内の練習は除く。設定では、マスのドラッグなどにトラックパッドを使うため）。そのときのクリックはそのまま渡します。Nonet を起動してから最初の1回だけ、画面の下に「Nonet のウィンドウが前面のときは、9マスは開きません」と出ます。ほかのアプリの上で試してください
- HUD はポインタのあるディスプレイに出ます。画面の端で輪が入らないときは収まる位置に寄せ、ポインタのほうを輪の真ん中へ動かします

### 選んで実行する

1. 指を置いたまま滑らせて、ポインタをアイコンへ向けます。向けた先のアイコンの下に白い円が出て、別のアイコンに移るたびにトラックパッドが軽く振動します
2. 実行したいアイコンで指を止めて、そのまま離します

白い円に乗っているアイコンが実行され、HUD が閉じます。

- アイコンで少し（0.1秒）止まってから離したときだけ実行します。狙ったアイコンへ滑らせて、そのまま離せば届く短さです。滑らせながら離したときや、通りかかっただけのアイコンは実行しません（ポインタを動かすつもりで指を滑らせたときに、実行しないため）
- マスはポインタの**向き**で決まります。真ん中から 8 つの向き（上・右上・右・右下・下・左下・左・左上）が設定の 3×3 の 8 つの周りのマスに、真ん中が中央のマスにあたります。向きの境目（隣のアイコンとの間）では、今のアイコンのまま少し粘るので、境目で指が揺れても切り替わりません
- HUD にはふだん文字が出ません。アイコンが並ぶだけで、プロファイルの名前も押すキー（⌘B など）も出しません。空きマスは小さな点です。文字が出るのは、マスに止めたときのマスの名前、ページの切り替えの案内、試用期間の知らせと、練習中の輪の下の「練習中」だけです
- アイコンは1つずつ暗い丸い台に白で描くので、下の画面が明るくても暗くても、写真の上でも同じように読めます

### やめる（キャンセル）

次のどれでも、何も実行せずに閉じます。輪の外・空きマスで離したときと、2本の指で離したときは、軽く2回振動します。キーで閉じたときと、時間切れで閉じたときは、振動しません。

- **輪の外で離す**: ポインタをアイコンの輪の外（真ん中から 134pt より遠く。アイコンの少し外側）まで動かして離します。線は見えませんが、越えるとアイコン全部が薄くなるので分かります。どの向きでも構いません
- **キーを押す**: 開いている間にどれかのキー（音量・輝度などのメディアキーを除く）を押すと、すぐに閉じます。そのキーは普段どおりアプリに届きます
- **空きマスで離す**: 中身のないマス（小さな点）に向けて離しても、何も起きません
- **開いた直後に離す**: ポインタを真ん中から動かす前に離しても、何も起きません（境目の線はありません。隣のアイコンとの間では、今のアイコンのままです）
- **名前を確かめる**: アイコンの意味に迷ったら、ポインタを向けたまま少し（0.6 秒ほど）止めます。そのアイコンの下に名前が出て、動かすと消えます。すぐに離す慣れた操作では出ません

開いたまま20秒たつと、自動で閉じます。

### 少し長く止めるマス

送信や録画のように取り消せない操作のマスは、インスペクタの「少し長く止めてから実行」をオンにしておくと安心です。

- このマスには、HUD のアイコンの右上に小さな印が付きます
- そのアイコンで指を少し（0.45秒）止めると、アイコンの周りに線が一周します。一周するとアイコンの下に白い円が出て、トラックパッドが1回振動します（VoiceOver では「離すと実行」と読み上げます）。一周してから離すと実行します。一周する前に離すと、何も実行しません

### 開いている間のトラックパッド

9マスを開いている間、ポインタはふだんどおり動きます（動きは前面のアプリにも届きます）が、クリックやスクロールは前面のアプリに届きません。指をトラックパッドに載せたまま外付けのマウスを使うと、そのクリックや移動も捨てられます（指を離すと閉じて、元に戻ります）。トラックパッドに触れていないときに届いたマウスの操作は、何も実行せずに閉じ、その操作はそのままアプリに届きます（指が離れたことを取りこぼしたときの備えです）。2本の指を置いたまま離したときも、何も実行しません。開いている間にトラックパッドから指の位置が届かなくなったとき（Magic Trackpad の接続や電池が切れた・Mac がスリープした・Nonet が別のトラックパッドに切り替えた など）も、光っているマスは実行せずに閉じます。

### ページ

9マスを開いたまま、ポインタを**輪のすぐ外へ出して止める**と、ページが切り替わります。止める向きで行き先が決まります。

- **右・左**（真横から上下 45° まで。斜めでも構いません）: そのプロファイルの次・前のページ
- **下**: グローバルのページ（「画面に置く」・「ユーティリティ」・ランチャー）へ。前面のアプリにプロファイルがあるときだけです
- **上**: グローバルのページから、下へ移る前に見ていたアプリのページへ戻ります

1. ポインタをアイコンの輪のすぐ外（真ん中から 134〜210pt ほど。アイコンの少し外側）まで動かし、そのまま止めます
2. 0.5秒ほどで切り替わります。ページが変わると2回、アプリとグローバルを切り替えると強めに1回、トラックパッドが振動します。右・左は止めたままなら、0.9秒ごとにさらに1ページ進みます。ページを一回りすると、止め始めたページの手前で止まります（続けるときは、いったんアイコンの方へ戻してから、もう一度止めます）
3. ポインタをアイコンへ向けて選び、離して実行します

止めている間は、その側の縁に白い矢印の円が出て、その縁に沿って線が伸びていきます。右・左なら、真ん中のアイコンの下に今のページを示す点も出ます。切り替わると、アイコンの輪が進んだ向きへ押し出され、次の輪が入ってきます（システム設定の「視差効果を減らす」がオンなら、動かさずに入れ替わります）。グローバルのページでは、アイコンの下の丸が少し紺色になり、切り替えた直後だけ、真ん中のアイコンの下にプロファイルの名前が出ます。

輪からさらに遠く（真ん中から 210pt ほどより外）まで動かして止めても、何も切り替わりません。迷ったときは、さらに外へ出してください。輪の外で離せば、どこで離しても、切り替えた後でもいつもどおり何も実行せずに閉じます。最後のページで右に止めると最初のページへ、最初のページで左に止めると最後のページへ回ります。回るのはアプリのページとグローバルのページ、それぞれの中だけです（ページが1つしかないときは、左右には何も切り替わらず、矢印も出ません。0.5秒止めると、真ん中のアイコンの下に「左右に送るページはありません」と出ます）。

**2本指で左右にスワイプ**しても、そのプロファイルの中でページを切り替えられます。2本指を左へ動かすと次のページで、1回のスワイプで1ページ進みます。最後のページの次は最初のページへ回ります（ページが1つしかないときは、軽く2回振動します）。**2本指で上下にスワイプ**すると、アプリのページとグローバルのページを切り替えます。2本指を奥へ動かすとグローバルのページへ、手前へ動かすとアプリのページへ戻ります（切り替える先が無いときは、軽く2回振動します）。スワイプした後は、指を1本だけ離し、残った指をもう一度滑らせてからマスで離します。滑らせずに離したときと、2本とも離したときは、何も実行しません。

1つのプロファイルに最大3ページまで置けます。アプリのプロファイルがあるアプリでは、グローバルのページへは下で移ります（アプリのページの右には続きません）。

アプリのプロファイルが無いアプリでは、グローバルのページだけを使うので、上や下で止めても切り替わりません。代わりに、真ん中のアイコンの下に「このアプリのページはまだありません」と出ます。設定の「プロファイル」でそのアプリを足すと、そのアプリのページができて、上下で切り替えられるようになります。前面にあるときの使い方を「グローバルを使う」にしたアプリでは、「このアプリはグローバルのページを使います」と出ます。

### グローバルとランチャー

前面のアプリにプロファイルがあれば、そのアプリの9マスを使います。プロファイルのないアプリの前では、どのアプリでも使える「グローバル」のプロファイルを使います。

グローバルのプロファイルの最初のページは、最初は「画面に置く」の9マスです（左上・上半分・右上・左半分・最大化・右半分・左下・下半分・右下。「[画面に置く](#画面に置く)」）。2ページ目は「ユーティリティ」の9マスです（撮影と収録・絵文字と記号・Spotlight・消音・画面を消す・画面をロック。「[ユーティリティ](#ユーティリティ)」）。その後ろに、よく使うアプリを最大9個（1ページ）並べたランチャーが続きます。Dock に置いてあるアプリを Dock の順に先に並べ、残りを Mac に入っているよく使うアプリで埋めます。macOS 26 でなくなった Launchpad の代わりに使えます。中身はほかのプロファイルと同じように自由に変えられます。

「画面に置く」と「ユーティリティ」のページは、消した後でも、設定の「＋」（ページを追加）からまた足せます。前の版から Nonet を使っていて、グローバルにこのページが無いときも同じです（「[ページと9マス](#ページと9マス)」）。

### ユーティリティ

グローバルの2ページ目「ユーティリティ」には、どのアプリの前でも同じように使う操作を9つ置いてあります。「最近のスクショ」のほかは、macOS のショートカットを送るキー入力のマスか、短いスクリプトのマスなので、新しい許可は要りません（「最近のスクショ」は、初めて使うときにスクリーンショットの保存先を読む許可を求めます）。

| | | |
|---|---|---|
| 範囲を撮影（⇧⌘4） | 撮影と収録（⇧⌘5） | 収録を止める（⌃⌘Esc） |
| 絵文字と記号（⌃⌘Space） | 撮影してコピー（⌃⇧⌘4） | 最近のスクショ |
| 消音の切り替え | 画面を消す | 画面をロック（⌃⌘Q） |

- **範囲を撮影**: 範囲を選んで撮り、ファイルに保存します
- **撮影してコピー**（真ん中）: 範囲を選んで撮り、ファイルにせずクリップボードに入れます。そのままチャットや書類に貼れます
- **撮影と収録**: macOS のスクリーンショットのツールバーを出します。ウインドウや画面全体の撮影と、画面の収録はここから始めます
- **収録を止める**: 画面の収録を止めます（メニューバーの停止ボタンと同じです）
- **絵文字と記号**: 文字を入力しているところで、絵文字と記号の一覧を出します
- **最近のスクショ**: 最近撮ったスクリーンショットを並べたトレイを出します。クリックでコピー、ドラッグで添付できます（「アクションの種類」の「[最近のスクショ](#最近のスクショ)」）
- **消音の切り替え**: 音を消す・戻すを切り替えます（スクリプトで `set volume` を使います）。消音できない出力先では、失敗と表示します
- **画面を消す**: ディスプレイをスリープさせます（スクリプトで `pmset displaysleepnow` を使います）。Mac 本体はスリープしません
- **画面をロック**: すぐに画面をロックします。押し間違えるとパスワードを打ち直すことになるので、少し長く止めてから離すと実行します（「[少し長く止めるマス](#少し長く止めるマス)」）

撮影・収録・絵文字と記号・ロックのキーは、macOS 全体のショートカットです。**システム設定 › キーボード › キーボードショートカット** で変えたりオフにしたりしていると、マスを実行しても何も起きません。そのときは、マスの「送るキー」を変えた後のキーに合わせてください。

Mission Control・アプリの一覧・デスクトップの切り替えは、トラックパッドの3本指・4本指の操作で出せるので、このページには入れていません。

### 触覚

9マスが開いたときと、指がマスの境界をまたぐたびに、トラックパッドが軽く「コツッ」と振動します。実行したときと、少し長く止めるマスを止め終えたときは1回、ページが変わったときは2回、アプリのページとグローバルのページを切り替えたときは強めに1回振動します。何も実行せずに閉じたとき（輪の外・空きマスで離した・2本の指で離した・ページが1つしかないときの左右のスワイプなど）と、試用期間の終了・アクセシビリティの許可がない・パスワードの入力中で開かないときは、軽く2回振動します。キーで閉じたときと、時間切れのときは振動しません。設定の「触覚」でオフにできます（感圧タッチのトラックパッドでだけ振動します）。

## プロファイルを編集する

Nonet のメニューの「◯◯ のマスを編集…」（◯◯は前面のアプリ）で、設定のウィンドウの「プロファイル」のタブを開きます。左から、プロファイルの一覧・9マス・インスペクタの3つの列に分かれています。

### プロファイルの一覧

- いちばん上の「グローバル」（「既定」の印）は、プロファイルのないアプリで使う9マスです。消すことはできません
- その下の「アプリ」に、アプリのプロファイルが並びます。ドラッグで並べ替えられます。いま前面のアプリで使われているプロファイルには「使用中」の印が付きます
- 「プロファイルを追加」で、インストール済みのアプリから選んで作ります。プリセットのあるアプリは、最初から中身が入ります。一覧にないアプリは「一覧にないアプリを選ぶ…」で選べます
- プロファイルを右クリック（Control キーを押しながらクリック）すると、「前面にあるとき」の3つの選択肢と、「複製して別のアプリに使う…」「プリセットに戻す…」（プリセットのあるアプリだけ）「このプロファイルを書き出す…」「削除…」が出ます。Delete キーでも削除できます。削除する前に確かめます（⌘Z で元に戻せます）
- **プロファイルを整理…**: アプリのプロファイルが2つ以上あると、一覧の下（とプロファイルの右クリック）に出ます。使わないアプリのプロファイルにチェックを付けて、まとめて削除します（「すべて選択」「選択を解除」、この Mac で見つからないアプリがあれば「見つからないアプリを選択」も）。確かめるのは1回で、以前の設定の控えも1つだけ残し、⌘Z かグリッドの下の「元に戻す」で、消したものがすべて元の位置に戻ります
- **前面にあるとき**: 9マスの右上（またはプロファイルの右クリック）で、そのアプリが前面にあるときの使い方を「このプロファイル」「グローバルを使う」「このアプリでは Nonet を使わない」から選べます。「グローバルを使う」にしたプロファイルには「グローバル」の印が付き、そのアプリの前でもグローバルのマスを使います（このプロファイルのマスは残ります）。「このアプリでは Nonet を使わない」にしたアプリには「オフ」の印が付きます（9マスの上の説明の横にも同じ印が出ます。マスはそのまま直せます）。そのアプリでは、強く押し込んでも9マスは開かず、トラックパッドもキーもいつもどおり働きます。Nonet のメニューの「このアプリでは使わない」でも切り替えられます
- アプリのプロファイルが8個以上あると、一覧の上に「名前・マス・キーで絞り込み」の欄が出ます（⌘F でいつでも出せます。Esc か ×（絞り込みをやめる）で閉じます）。プロファイルの名前と、どのプロファイルのマスの名前・中身・送るキー（`⌘B` のように修飾キーを付けて入れます）でも探せ、結果は「Xcode › ビルド」のように並びます
- 一覧の下の「Nonet を有効にする」は、一般の設定と同じスイッチです

### ページと9マス

中央に、選んだプロファイルのページと 3×3 のマスが出ます。

- 「ページ 1」「ページ 2」…（⌘1〜⌘3）で切り替えます。「＋」（ページを追加）で、空のページか、「画面に置く」「ユーティリティ」「メディア」の9マスが入ったページを足します（最大3ページ）。ページの横の「…」（ページの操作）の「このページを削除…」か、ページを右クリックして「このページを削除…」で、選んでいるページを消します。中身のあるマスがあるページは、消す前に確かめます。「…」からは、ページの追加と「名前を変更…」もできます
- ページのボタンをダブルクリックするか、右クリックして「名前を変更…」を選ぶと、「デバッグ」「Git」のようにページに名前を付けられます。名前はメニューバーの早見表の題名に「Xcode のマス · デバッグ」のように出ます。アプリのページとグローバルのページを切り替えたときも、真ん中のアイコンの下に少しの間出ます。空にすると「ページ 1」などに戻ります
- マスをクリックで選び、ドラッグで入れ替えます。「ページ 2」などの上へドラッグすると、そのページの空きマスへ移ります。選んでいるマスは塗られます。キー（Delete・矢印キーなど）がグリッドに届くときはアクセント色、ほかの場所（プロファイルの一覧や文字の欄）に届くときは灰色です
- マスにポインタを重ねると、名前（長くて切れていても全部）と、何をするか（送るキー・開くアプリなど）が出ます
- 矢印キーで選ぶマスを移り、Delete キーで空にします。ほかのキーは「作り込むときの操作」
- マスを右クリックすると「複製」「削除」「このマスをテスト実行」が出ます。選んだ項目は、右クリックしたマスを選んでから行います（空にしたときは「「ビルド」を空にしました」のように、どのマスかを知らせます）。空きマスでは「アクションを追加」から種類を選んで作れます。コピーと貼り付け、隣との入れ替えはキーで行います（「作り込むときの操作」）

### 元に戻す・以前の設定に戻す

- マスの変更（空にする・削除・複製・作る・入れ替える・ほかのページへ移す・メニューから割り当てる・貼り付ける）、インスペクタでの変更（マスごとに1つ）、ページの追加と名前の変更、「プリセットに戻す…」、「複製して別のアプリに使う…」、プロファイルとページの削除は、⌘Z で元に戻せます（⇧⌘Z でやり直し）
- マスを空にしたとき・中身のあるマスを置き換えたとき・プロファイルやページを削除したときは、9マスの下に出る「元に戻す」でも戻せます。その後でまた変えたマスは、元に戻さずにそう知らせます
- 読み込みでの置き換えは ⌘Z では戻せません。代わりに、次の控えから戻します
- Nonet は、設定を変えている間（1時間に1回まで）と、プロファイルやページの削除・読み込み・プリセットに戻す・以前の設定に戻す前に、その時点の設定の控えを `~/Library/Application Support/Nonet/Backups/` に新しいものから10個残します。設定の「Nonet」のタブの「書き出しと読み込み」の「以前の設定に戻す…」で控えを選び、「戻す…」→「この設定に戻す」で、そのときのプロファイルと設定に戻せます。戻す前の設定も控えに残るので、後で戻せます

### 作り込むときの操作

- **プロファイル**: 右クリックの「複製して別のアプリに使う…」で、ページとマスをすべて写した別のアプリのプロファイルを作ります（元のアプリのメニュー項目を押すマスは、新しいアプリのメニューを押します。VS Code から Cursor へ写すときなど）。「プリセットに戻す…」は、確かめてからマスをプリセットの中身に置き換えます
- **マス**: ⌘C / ⌘V でコピーと貼り付け。ほかのプロファイルのマスにも貼れるので、プロファイルの間でマスを写すのにも使えます
- **9マスで使うキー**: ⌘D で複製、⌘⌫ で空にする、⌥⌘＋矢印キーで隣と入れ替え、Return で表示名の欄へ
- **プロファイルのタブで使うキー**: ⌘1〜⌘3 でページを切り替え、⌘F でプロファイルの絞り込み

### インスペクタ

右の列で、選んだマスを設定します。変更はその場で保存されます。

- **空きマス**: アクションの種類のボタンを押して作ります
- **表示名**: マスの下に出る名前です。空のときは、中身から自動で付けた名前を使います
- **アイコン**: 表示名の左のアイコンを押して選びます。「記号」（SF Symbols。英語の名前で検索します）か「アプリ」（「このアプリのアイコンを使う」。アプリを開くマス・メニュー項目のマスか、アプリのプロファイルで使えます）。「既定のアイコンに戻す」で元に戻ります
- **アクションの種類**: キー入力・開く・画面に置く・スクリプト・ショートカット・メニュー項目・AI・ファイル（次の「アクションの種類」）
- **少し長く止めてから実行**: オンにすると、HUD でこのマスに指を少し長く止めてから離したときだけ実行します（「基本の使い方」の「[少し長く止めるマス](#少し長く止めるマス)」）
- **このマスをテスト実行**: その場で実行して、「実行しました」かエラーを表示します。スクリプトやショートカットの出力は、その下に出ます（選んでコピーできます）。アプリのプロファイルでは、そのアプリを前面に出してから実行します。グローバルのマスは、設定を開く前に使っていたアプリの前で実行します。キー入力のように前面のアプリに入力を送るマスは、そのアプリが前面に出て、設定のウィンドウがキーを受けなくなるまで待ちます。間に合わなければ、設定のウィンドウにキーを送らずに「Xcode が前面になりませんでした」のように表示します
- **このマスを空にする**: 中身を消して空きマスに戻します

### メニューから割り当て

ショートカットを調べなくても、アプリのメニューから選んで割り当てられます。

1. 対象のアプリを起動しておきます
2. 9マスの右上の「メニューから割り当て」を押し、ポップアップメニューからアプリを選びます
3. 「メニューを検索」で探し、項目をマスへドラッグします。ダブルクリックか、右クリックの「マスに入れる」でも入ります。そのときは、選んでいるマスが空きマスかメニュー項目のマス（項目をまだ選んでいないものも）ならそのマスに、そうでなければ空いているマスに入ります

中身のあるマスに入れると、そのマスは置き換わります（⌘Z か、9マスの下の「元に戻す」で戻せます）。インスペクタの「メニューから選ぶ…」で開いたときは、編集しているメニュー項目のマスを選んだままなので、ダブルクリックした項目がそのマスに入ります。インスペクタに戻るときは、パネルの右上の「×」（インスペクタに戻る）を押します。

## アクションの種類

### キー入力

前面のアプリにキーを送ります。「送るキー」の欄（「クリックして記録」）を押してから、送りたいキーをそのまま押すと記録されます。

- `⌘B`、`⇧⌘4` のような組み合わせ
- `⌘L → ⌘C` のような、続けて押すキー（4つまで。40ミリ秒の間隔で送ります）

記録しているとき（欄に「キーを押してください…」と出ている間）は、次のように動きます。

- 続けて押すと連続キーになります。Return や Tab もそのまま記録します
- 「完了」を押すか、ほかの場所をクリックすると決まります。4つ押したときも決まります
- Esc を押すと、何も変えずに記録をやめます（「やめる」も同じ）。Esc キーそのものを送りたいときは「Esc を加える」を押します
- 押し間違えたキーは、⌫（最後のキーを消す）で消せます

⌘Tab・⌘Space やスクリーンショットの ⇧⌘4 のように、macOS が先に使うキーは記録欄に届きません。そのときは、記録欄の下の「表記で入力」の欄にキーを書いて「決定」を押します。`⇧⌘4` のような記号のほか、`cmd+shift+4` のような書き方も読めます。続けて押すキーは `→` か `,` で区切ります。

JIS 配列でも、`⌘[` などが正しく届きます。今のキー配列では打てないショートカット（ドイツ語の配列の `⌘[` など）は、前面のアプリに同じショートカットのメニュー項目があれば、その項目を押します。

キーを送る直前に、前面のアプリが9マスを開いたときのままか確かめます。変わっていたとき（前のマスで開いたアプリが前に出てきたときなど）は、別のアプリにキーが届かないよう、送らずに「前面のアプリが変わったため、キーを送りませんでした」と表示します。

スクリーンショットもキー入力のマスで撮れます。プリセットの「範囲を撮影」は、⇧⌘4 を送るだけのキー入力のマスです。グローバルの「ユーティリティ」のページには、撮影と収録のマスがまとめてあります（「[ユーティリティ](#ユーティリティ)」）。

### 開く（アプリ・URL）

アプリか URL を開きます。「開くもの」で「アプリ」か「URL」を選びます。

- **アプリ**: 起動していなければ起動し、起動中なら前面に出します。「開くアプリ」の「アプリを選ぶ…」で、インストール済みのアプリから選びます。一覧にないアプリは「一覧にないアプリを選ぶ…」で選べます。開くアプリの名前は、インスペクタと、マスにポインタを重ねたときのヘルプに出ます。「前面のときは隠す」をオンにすると、もう一度実行したときに隠れるので、アプリの切り替えのように使えます
- **URL**: 「開く URL」を既定のアプリで開きます。`https://` を省いた場合は自動で補います（`localhost` などは `http://`）。`obsidian://` のような、アプリ独自の URL も使えます。`/` や `~` で始めると、ファイルやフォルダとして開きます

### 画面に置く

前面のアプリのウインドウを、画面の決まった場所に置きます。「置く場所」で、左上・上半分・右上・左半分・最大化・右半分・左下・下半分・右下の9つから選びます。画面の使える範囲（メニューバーと Dock を除く）を 3×3 に分けた場所で、「上半分」「左半分」は使える範囲の半分、「最大化」は使える範囲いっぱいです。

- HUD でこのマスを光らせている間、置く枠が薄い青で画面に出て、「離すと、ここに置きます」と添えます。マスで離すと、そのウインドウがそこへ移ります。輪の外へ出せば枠は消えます
- 動かすのは、9マスを開いたときに前面だったアプリの、いちばん手前のウインドウです（VoiceOver では HUD の名前に「Safari のウインドウ」のように、何を動かすかを添えて読みます）
- ウインドウのあるディスプレイで置きます。フルスクリーンのウインドウや、大きさの決まったウインドウ（システム設定など）は動かせず、「このウインドウは動かせませんでした」と出ます。ウインドウが無いアプリ（Finder でウインドウを閉じているときなど）では「前面のウインドウが見つかりません」と出ます
- 最初の設定では、グローバルの最初のページがこの9マスです（「[グローバルとランチャー](#グローバルとランチャー)」）。プロファイルのあるアプリの前では、ポインタを輪の下の外へ出して止めるとこのページへ移ります。プロファイルの無いアプリでは最初のページです。消しても、設定の「＋」（ページを追加）の「画面に置く」でまた足せます

### 再生・音量

キーボードの再生・音量・明るさのキーと同じ働きをします。どのアプリが前面でも効き、macOS の音量や明るさの表示が出ます。

- **押すキー**: 再生／一時停止・次の曲・前の曲・音量を上げる・音量を下げる・消音・明るくする・暗くする から選びます
- 音量と明るさは、1回で2段変えます（9マスを開き直す手間に見合うように）
- 設定の「＋」（ページを追加）の「メディア」で、真ん中が再生／一時停止、左右が前と次の曲、上下が音量、左下が消音、右の上下が明るさのページを足せます
- 明るさは、Mac の内蔵ディスプレイと、明るさを変えられる Apple のディスプレイで効きます

### スクリプト

「実行するスクリプト（zsh）」の欄に書いた zsh のスクリプトを実行します（`/bin/zsh -l -c`）。欄の右上の「?」を押すと、下の環境変数の説明が出ます。

- **実行の仕方**
  - 裏で実行: 終わるまで待ちます。「制限時間」（既定 60秒、1〜3600秒）を過ぎると止めます。失敗したら（終了コードが 0 以外）、エラー出力の最後の部分を画面に表示します（エラー出力が空なら、標準出力の最後の部分）。0.5秒で終わらないときは、終わるまで画面の下に「「◯◯」を実行中…」と出ます。実行中は、Nonet のメニューの「実行中の「◯◯」を止める」で止められます
  - ターミナルで実行: ターミナルの新しいウィンドウで実行します。`claude` のような対話型のコマンドに向いています。iTerm2 が入っていれば、設定の「一般」の「「ターミナルで実行」のアプリ」で iTerm2 に変えられます
- **出力**（裏で実行のときだけ）: スクリプトの標準出力があれば、最後の改行を除いて結果のパネルに出します（AI の「画面に表示」と同じで、文を選んでコピーできます）。出したくないときは `> /dev/null` で捨てます。ログインシェルの設定ファイル（`~/.zprofile`・`~/.zlogin` など）が表示するもの（ssh-agent の「Agent pid …」など）は含めません。出力が空のとき・空白と改行だけのとき・テキストでないときは、何も出しません。64 KB より長いときは、「（出力が長いため、終わりの 64 KB だけを表示しています）」の行を付けて終わりの 64 KB だけを出します（スクリプトは成功のままです）
- **作業フォルダ**: プロジェクトのフォルダ（下記）。分からなければホームフォルダ
- **環境**: 裏で実行するときはログインシェル（`zsh -l`）で動き、`PATH` はターミナルと同じもの（Nonet の起動時に `~/.zshrc` まで読んで調べたもの）を使います。`~/.zshrc` のエイリアスや関数を使えるのは「ターミナルで実行」のときだけです（ターミナルで実行するときは `~/.zshrc` を読み込みます）。`~/.zshrc` を変えたら Nonet を終了して開き直してください

#### スクリプトに渡す環境変数

実行したときの前面のアプリの情報を渡します。**値がないものは設定されません**。

| 変数 | 中身 | 例 |
|---|---|---|
| `NONET_APP_BUNDLE_ID` | 前面のアプリの bundle ID | `com.apple.dt.Xcode` |
| `NONET_APP_NAME` | 前面のアプリの名前 | `Xcode` |
| `NONET_DOCUMENT_PATH` | 前面のウィンドウで開いている書類（Visual Studio Code・Cursor など、書類の場所を macOS に知らせないアプリでは空） | `/Users/you/dev/App/App.xcodeproj` |
| `NONET_PROJECT_DIR` | 書類から決めたプロジェクトのフォルダ | `/Users/you/dev/App` |
| `PROJECT_DIR` | `NONET_PROJECT_DIR` と同じ | `/Users/you/dev/App` |
| `NONET_BROWSER_URL` | ブラウザで表示中のページ（Safari・Google Chrome・Arc・Microsoft Edge・Brave） | `https://example.com/article` |
| `NONET_SELECTED_TEXT` | 選択中のテキスト | |

選択中のテキスト（`NONET_SELECTED_TEXT`）とブラウザの URL（`NONET_BROWSER_URL`）は、スクリプトにその変数の名前が書かれているときだけ読みます（読むために ⌘C を送ったり、ブラウザに問い合わせたりするため）。名前が書かれていないスクリプトでは、⌘C を送らず、ブラウザにも問い合わせません（オートメーションの確認も出ません）。選択中のテキストを直接読めないアプリでは、⌘C でコピーして読み、クリップボードは元に戻します。別のファイルのスクリプトを呼ぶだけのときは、コメントでよいので、使う変数の名前を書いておいてください（下の例）。ほかの変数（`NONET_APP_BUNDLE_ID`・`NONET_APP_NAME`・`NONET_DOCUMENT_PATH`・`NONET_PROJECT_DIR`・`PROJECT_DIR`）は、値があればいつも設定します。

Visual Studio Code と Cursor は、開いている書類の場所を macOS に知らせません（ウインドウの題名も「Code」だけです）。そのため、これらのアプリの前では `NONET_DOCUMENT_PATH` と `PROJECT_DIR` が空になり、プリセットの Claude Code のマスはホームフォルダで開きます。プロジェクトのフォルダで開きたいときは、スクリプトの `cd "${PROJECT_DIR:-$HOME}"` をそのフォルダの場所に書き換えてください。

プロジェクトのフォルダは次のように決めます。

- 書類が `.xcodeproj`・`.xcworkspace`・`.playground` か、パッケージの中の `.swiftpm` なら、その入っているフォルダ。Swift Playgrounds の `名前.swiftpm` なら、そのフォルダ自体
- ほかのファイルなら、上へたどって `.git` か `Package.swift` のあるフォルダ。見つからなければ、そのファイルのあるフォルダ
  - ホームフォルダの中では、ホームフォルダの手前までたどります（何段でもたどるので、Maven・Gradle・Android のような深いフォルダでも見つかります）
  - ホームフォルダの外（`/Volumes/SSD` など）では、書類から上へ32個のフォルダまでです。`/` や `/Volumes` のような、いちばん上のフォルダは調べません
  - ネットワーク上の場所の書類では探さず、そのファイルのあるフォルダを使います
  - 0.3秒のうちに調べ終わらないとき（眠っている NAS など）は、プロジェクトのフォルダはなしになり、スクリプトはホームフォルダで動きます

例:

```zsh
# Claude Code をプロジェクトのフォルダで開く（「ターミナルで実行」）
cd "$PROJECT_DIR" && claude

# プロジェクトを VS Code で開く
open -a "Visual Studio Code" "${PROJECT_DIR:-$HOME}"

# 表示中のページの URL をクリップボードへ
printf '%s' "${NONET_BROWSER_URL:?ブラウザが前面にありません}" | pbcopy

# 選択中のテキストを別のファイルのスクリプトに渡す（このコメントに NONET_SELECTED_TEXT と書いてあるので読みます）
~/bin/translate.sh
```

変数は必ず `"$NONET_SELECTED_TEXT"` のように `"` で囲んでください（空白や記号を含むことがあります）。ないかもしれない変数は `${変数:-既定値}` か `${変数:?メッセージ}` で扱うと安全です。`:?` のメッセージは失敗として画面に出ます。

### ショートカット

ショートカット.app のショートカットを実行します。「実行するショートカット」に名前を入れるか、横の一覧のボタン（ショートカットの一覧から選ぶ）から選びます。「選択中のテキストを渡す」をオンにすると、選択中のテキストを入力として渡します。

ショートカットがテキストを返したときは、最後の改行を除いて結果のパネルに出します（リッチテキストは文字だけにします。長いときは、スクリプトと同じく終わりの 64 KB だけを出します）。画像やファイルなど、テキストでないものを返したときと、何も返さないときは、何も出しません（どちらも失敗にはしません）。

### メニュー項目

アプリのメニュー項目を押します。「メニューから割り当て」で選ぶのがかんたんです（インスペクタの「メニューから選ぶ…」でも開き、ダブルクリックした項目が編集しているマスに入ります）。「押すメニュー項目」に、項目の場所・アプリ・キーが出ます。

- 対象のアプリが前面にあり、その項目のキー（ショートカット）が、アプリのメニューにあるその項目のキーと同じなら、キーを送ります（速い）。同じでないとき（アプリのアップデートでキーが変わった・メニューを読めない など）は、メニューを順にたどって押します。キーを送る直前に対象のアプリが前面でなくなっていたときも、キーは送らずにメニューを順にたどって押します
- キーがなければ（「なし（メニューを順にたどって押します）」）、アクセシビリティの機能でメニューを順にたどって押します
- 「再生」⇄「一時停止」や「ツールバーを表示」⇄「ツールバーを非表示」のように、押すと名前が変わる項目も、続けて使えます。名前が見つからなければ対になる名前で探し、それでもなければ、同じメニューに同じキー（ショートカット）の項目が1つだけならそれを押します
- 対象のアプリが起動している必要があります
- メニューの名前は macOS の言語で変わります。言語を変えたら割り当て直してください

### AI

選択中のテキストと「指示文」を、Mac の中の言語モデル（Apple Intelligence）に渡します。テキストが Mac の外に送られることはありません。

- 必要なもの: macOS 26 以降、Apple Intelligence に対応した Mac、**システム設定 › Apple Intelligence と Siri** で Apple Intelligence をオン（モデルのダウンロードが終わっていること）
- 結果の出し方:
  - 選択範囲を置き換える: 選択中のテキストを結果で置き換えます（クリップボードを通して ⌘V で貼り付け、クリップボードは元に戻します）。待っている間に前面のアプリが変わったときは、代わりにクリップボードにコピーします。アプリが選択範囲を知らせず ⌘C で読んだとき（貼り付けると、カーソルの位置に入ってしまうことがあるため）と、クリップボードの中身を元に戻せないとき（下の「[選択中のテキストを読めない](#選択中のテキストを読めない)」）は、貼り付けずに結果のパネルに出します
  - クリップボードにコピー
  - 画面に表示: 結果のパネルに出します。文を選んでコピーすることもできます。「コピー」で結果をコピーし、「閉じる」か Esc でパネルを閉じます
- 使えない Mac では、インスペクタと実行したときに理由を表示します
- 0.5秒で終わらないときは、終わるまで画面の下に「「◯◯」を実行中…」と出ます
- クリップボードを元に戻すとき、コピーしてあった画像は1つの形式だけを、Finder でコピーしたファイルはファイルだけを（アイコンの絵は除いて）戻します

### ファイル

Finder で選んでいるファイルを、ゴミ箱に入れる・名前を変更・複製します。Finder でファイルをクリックして選び、9マスを開いてこのマスを選ぶと、そのファイルにすぐ使えます。

- **操作**:
  - ゴミ箱に入れる: Finder の「ゴミ箱に入れる」と同じです。完全には削除しないので、ゴミ箱から戻せます。ゴミ箱の中のファイルと、ネットワーク上のファイルなどゴミ箱の無い場所のファイルは動かしません。操作を「ゴミ箱に入れる」にすると、「少し長く止めてから実行」が自動でオンになります（外せます）
  - 名前を変更: Finder の名前の変更（Return を押したときと同じ）を始めます。名前を入力して Return で決めます。1つだけ選んでいるときに使えます
  - 複製: 同じ場所に「◯◯のコピー」を作ります。大きなファイルは時間が掛かります（Finder に頼んで、最長10分待ちます）。0.5秒で終わらないときは、終わるまで画面の下に「「◯◯」を実行中…」と出ます
- **対象**: Finder が前面にあるとき、Finder で選んでいるファイルです（デスクトップのアイコンも含みます）。実行する直前の前面のアプリで確かめるので、別のアプリが前面のときは、裏の Finder のウインドウで選んだままのファイルを動かさないよう、何もせずにエラーを表示します。何も選んでいないときも同じです。シンボリックリンクは、リンク先を動かしてしまうので動かしません。選んでいるファイルが500個を超えるとき、ホームフォルダ・ホームの標準のフォルダ（デスクトップ・書類など）・ディスクの一番上・システムのフォルダ・ほかの利用者のホームが含まれるときは、何もしません
- **許可**: 初めて使うときに、macOS が「Nonet が Finder を操作しようとしています」と確かめます（「困ったとき」の「[オートメーションの許可を求められた](#オートメーションの許可を求められた)」）。Nonet が読むのは、Finder で選んでいるファイルの場所だけで、ファイルの中身は読みません
- 設定の「このマスをテスト実行」は、実行する前に確かめます（設定の画面からは、Finder で何を選んでいるか見えないため）
- Finder のプリセットの2ページ目（「選んだファイル」）に、複製・名前を変更・ゴミ箱に入れる（少し長く止めてから実行）が入っています

### 最近のスクショ

macOS のスクリーンショットの保存先（⇧⌘5 の「オプション」で選んだ場所。既定はデスクトップ）から、最近のスクリーンショットと画面の収録（動画）を新しい順に、HUD を出していた場所の近くの小さなパネル（トレイ）に並べます。撮ったものを、デスクトップを探さずにすぐ添付・貼り付けできます。

- **並べる数**: 3・5・8・12 から選びます（既定は5。8と12は2段に並べます）
- **画面の収録（動画）も並べる**: オフにするとスクリーンショットだけを並べます（既定はオン）。収録は右下に再生の印と「収録・」が付きます

- **クリック**: その1枚をクリップボードに入れ、トレイを閉じます（画面の下に「スクリーンショットをコピーしました」）。チャットやメールの入力欄で ⌘V を押すと画像として、Finder ではファイルとして貼り付きます。収録はファイルとしてコピーするので、チャットやメールでは添付になります
- **ドラッグ**: その1枚をファイルとしてつまみます。チャット・メール・ブラウザの添付欄や、Finder のフォルダに落とせます
- **キーボード**: ↑↓←→ で選び、Return でコピーします。Esc で閉じます
- トレイの外をクリックしても閉じます。前面のアプリは替わらないので、閉じたらそのまま入力を続けられます
- 「フォルダを開く」で、保存先を Finder で開きます
- 並べるのは、macOS が撮ったスクリーンショット（印の付いた画像）と、ファイル名が「スクリーンショット」「Screenshot」（⇧⌘5 で名前を変えていればその名前）で始まる画像です。画面の収録は、印の付いた動画か、名前が「画面収録」「Screen Recording」で始まる動画です
- **許可**: 初めて使うときに、macOS が「Nonet がデスクトップフォルダ内のファイルにアクセスしようとしています」のように確かめます（保存先が書類・ダウンロードなら、そのフォルダ）。読むのはファイルの一覧と、並べるスクリーンショットだけです。許可しなかったときは、トレイに「保存先のフォルダを読む許可がありません」と「システム設定を開く」が出ます（**システム設定 › プライバシーとセキュリティ › ファイルとフォルダ** で Nonet をオンにします）
- グローバルの「ユーティリティ」のページに入っています

## 設定

Nonet のメニューの「設定…」で、設定のウィンドウの「一般」のタブが開きます。ウィンドウの上で「プロファイル」「一般」「Nonet」のタブを切り替えます。「プロファイル」のタブは「[プロファイルを編集する](#プロファイルを編集する)」で、「Nonet」のタブのライセンスと情報は「[試用とライセンス](#試用とライセンス)」「[アップデートと情報](#アップデートと情報)」で説明します。一般のタブの項目は、次のまとまりに分かれています。

### 書き出しと読み込み

「Nonet」のタブの「書き出しと読み込み」で、プロファイルを `.nonetprofile` のファイルに書き出して、バックアップしたり、別の Mac やほかの人と共有したりできます。書き出すのはプロファイル（9マスの中身）だけで、一般の設定やライセンスは含みません。

- **書き出す…**: すべてのプロファイルを1つのファイルに書き出します。1つだけ書き出すときは、プロファイルの一覧で右クリックして「このプロファイルを書き出す…」を選びます
- **読み込む…**: ファイルのプロファイルを加えます（20MB を超えるファイルは読み込めません）。Finder で `.nonetprofile` のファイルをダブルクリックしても、同じように読み込みます。次のどちらかに当たるときは、先に「「ファイル名」を読み込みますか？」と確かめます
  - 今の設定が置き換わる（ファイルにグローバルが入っている、または同じアプリのプロファイルがすでにある）: 置き換わるものを並べます
  - 何かを実行するマスがある（スクリプト・キー入力・メニュー項目・AI・ショートカット.app のショートカット・Finder で選んだファイルをゴミ箱に入れる、名前を変える、複製するファイルのマスと、Mac の中のファイルを開く URL、別のものを動かす URL（ショートカットの実行・ssh・共有フォルダなど））: 何も置き換わらなくても確かめます。マスごとに「プロファイル › マス」と中身のすべてを、スクロールできる欄に切らずに並べます。スクリプトはすべての行、キー入力は押すキーのすべて、メニュー項目は場所とショートカット、AI は指示と結果の出し方、ショートカットは名前、ファイルは操作、URL は開く場所です。見えない文字は「⟨U+202E⟩」のような形で見せます
- **以前の設定に戻す…**: 削除や読み込みの前などに残した控えから、以前の設定に戻します（「プロファイルを編集する」の「元に戻す・以前の設定に戻す」）

中身の欄では、Return と同じ働きのキー（または ⌃ の付いたキー）を押すマスと、注意が要る命令（curl・wget・base64・eval・`| sh`（bash や zsh も）・osascript・rm -rf）を含む行に、橙色の印と説明が付きます。何かを実行するマスがあるときは、欄を最後までスクロールするまで「読み込む」「置き換えて読み込む」「新しいプロファイルだけ追加」を押せません（「最後までスクロールして中身をすべて確かめると、読み込めます」と出ます）。

確かめるときは、中身を見て次のどれかを選びます。

- 置き換えて読み込む: 置き換わるものがあるときに出ます。一覧のものをファイルの中身で置き換え、新しいアプリのプロファイルも加えます。⌘Z では戻せませんが、読み込む前の設定は「以前の設定に戻す…」に残ります
- 読み込む: 置き換わるものがないときに出ます。ファイルのプロファイルを加えます
- 新しいプロファイルだけ追加: 今のプロファイルには触れず、まだないアプリのプロファイルだけ加えます（置き換わるものと、加えるものの両方があるときだけ出ます）
- キャンセル: 何も変えません

どちらにも当たらなければ、確かめずにそのまま加えます。結果（追加した数・置き換えた数・読み込まなかった数）は、ウィンドウの上の帯に出ます。メニュー項目のマスのキー（ショートカット）は1つのキーだけを読み込みます。それより長いものは捨て、その項目はメニューを順にたどって押します。1つのキーでも、アプリのメニューにあるその項目のキーと違えば、実行するときはメニューを押します（「アクションの種類」の「メニュー項目」）。

**ほかの人から受け取ったプロファイルは、信頼できるものだけを読み込んでください**（スクリプトやキー入力はあなたの権限で動きます）。読み込む前の確認で、マスの中身をすべて確かめてください。スクリプトを含むときは、読み込んだ後の帯でも知らせます。

## 試用とライセンス

- 初めて起動した日から**14日間**、すべての機能を無料で使えます。残り日数は Nonet のメニューと、設定の「Nonet」のタブに出ます
- 残りが3日以下になると、アイコンに「!」が付き、メニューのいちばん上の行に残り日数が出ます。HUD の上にも「試用期間は残り3日です」のように1日に1回出ます。Nonet のメニューの「Nonet を購入…」「ライセンスキーを入力…」から、いつでも購入・登録できます
- 試用期間が終わると、強く押し込んでも9マスは開かず、画面の下に「試用期間が終了しました」「メニューバーの Nonet から購入・登録できます」と出ます（軽く2回振動します。メニューバーのアイコンが隠れているときは「アプリケーションフォルダから Nonet を開くと、設定で購入・登録できます」）。設定はそのまま残ります。小さなウィンドウ「Nonet の試用期間が終了しました」（1日に1回まで。「購入する」「ライセンスキーを入力…」「あとで」）と、設定のウィンドウの上の帯（「購入する」「ライセンスキーを入力…」）からも購入・登録できます
- 購入すると、ライセンスキーがメールで届きます（遅くとも24時間以内）。1つのライセンスで、あなたが使うすべての Mac に使えます。購入から30日以内なら全額を返金します
- 返金したライセンスのキーと、公開されてしまったキーは、その後に出る版の Nonet では使えません。登録していたキーが使えなくなったときは、「Nonet」のタブに理由が出て、試用期間が残っていれば試用に戻ります

設定の「Nonet」のタブのライセンスの欄:

- **状態**: 「試用期間中（残り14日・11月14日まで）」「登録済み」「試用期間が終了しました」のどれかです。登録済みなら、登録者・発行日・ライセンス ID も出ます
- **買い切りのライセンス**: 「購入する」で購入ページを開きます（登録していないときだけ出ます）
- **購入済みの方**: 購入時のメールに書かれたライセンスキーを欄に貼り付けて「登録」を押すと、すぐに使えるようになります。「License key:」のような前後の文字ごと貼り付けても、キーの部分だけを読みます。キーはこの Mac の中で確かめるので、ネットワークもアカウントも要りません。登録できないときは理由と次にすることが出ます（その横の「お問い合わせ…」で問い合わせのメールを作れます）。キーが見つからないときは「ライセンスキーが見つからないときは」から。購入のメールや、購入を終えたページの「Nonet に登録する」を押すか、`.nonetlicense` のファイルを開くと、キーが入った状態で「このライセンスキーを登録しますか？」と尋ねます（尋ねずに登録することはありません）
- **ライセンスキー**: 登録済みのとき、「キーをコピー」でキーをコピーして、ほかの Mac にも登録できます。「別のキーを登録…」で別のキーに替えられます
- **この Mac から登録を消す**: 「登録を消す…」を押すと確かめます。「キーをコピーして消す」はキーをクリップボードにコピーしてから、「消す」はそのまま、この Mac からライセンスキーを消します（コピーしておけば、あとで貼り付けて登録し直せます）。Mac を手放すときなどに使います。同じキーは、ほかの Mac でもそのまま使えます

## アップデートと情報

新しい版は自動で確認されます。見つかると、メニューバーのアイコンの右上の点が大きくなり、Nonet のメニューの「アップデートを確認」が「アップデートがあります…」に変わります。選ぶと、新しい版の知らせが出ます（起動した直後に見つかったときと、メニューバーのアイコンが隠れていて印が見えないときは、すぐに知らせが出ます）。Nonet のメニューの「アップデートを確認」で、いつでも確認できます。

設定の「Nonet」のタブには、ライセンスの欄と「書き出しと読み込み」の下に、バージョン・「アップデートを確認」・「利用ガイド」（このガイド）・「プライバシー」（プライバシーポリシー）・「お問い合わせ…」・「Nonet をアンインストール…」と、Nonet が使っているサードパーティのソフトウェアのライセンスがあります。Nonet を英語で使っているときは、購入ページ・利用ガイド・プライバシーポリシーは英語のページが開きます。設定や案内のウィンドウが前にあるときに、メインメニューの「Nonet について」を選ぶと、この欄を開きます。

「お問い合わせ…」を押すと、メールのアプリで問い合わせのメールが開きます。本文に入るのは、Nonet と macOS の版・Mac の機種・キーボードの種類だけです（ライセンスキーや設定の中身は入りません）。送るかどうかは、あなたが決めます。

## 困ったとき

Nonet が動けないときは、Nonet のメニューのいちばん上の行と、設定のウィンドウの上の帯に理由が出ます。

### 「アクセシビリティの許可が必要です」と出る

許可がない間は、トラックパッドを強く押し込んでもふつうのクリックになり、9マスは開きません。

- 設定のウィンドウの上の帯の「システム設定を開く」（最初は macOS の確認が出ます。もう一度押すとシステム設定が開きます）か、Nonet のメニューの「アクセシビリティを許可…」を押します
- **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet をオンにします。許可されると自動で動き出します
- オンになっているのに効かないとき（アップデートの後など）は、一覧から Nonet を選んで「−」で外し、「＋」でもう一度追加してオンにしてください（設定のウィンドウの帯と、初回の案内の許可の画面にも書いてあります）

### 「パスワードの入力中は動きません」と出る

パスワード欄にカーソルがあるときや、ターミナルの「セキュアキーボード入力」がオンのとき、macOS はほかのアプリにキーを見せないので、Nonet は9マスを開きません（強く押し込むと、画面の下に「パスワードの入力中は開きません」と出て、そのクリックはそのまま渡します。同じ知らせは30秒に1回まで）。パスワード欄から離れるか、ターミナル › セキュアキーボード入力 をオフにしてください。離れると自動で戻ります。帯の「もう一度確かめる」ですぐに確かめ直せます。

### 「トラックパッドが見つかりません」と出る

MacBook の内蔵トラックパッドか Magic Trackpad が必要です。マウスだけでは使えません。Magic Trackpad をつないだり、つなぎ直したりしたときは、Nonet が自動で見つけ直します（10秒ほどかかることがあります）。帯の「もう一度確かめる」で、すぐに確かめ直すこともできます。それでも反応しないときは、Nonet のメニューの「終了」で Nonet を終了し、もう一度起動してください。

### まったく反応しない

- Nonet のメニューの「Nonet を有効にする」にチェックが付いているか確かめます
- 前面のアプリで「このアプリでは使わない」にチェックが付いていないか確かめます（プロファイルの一覧で「オフ」の印が付いたアプリです）
- 試用期間が終わっていないか確かめます（Nonet のメニューに「試用期間が終了しました」と出ます）
- 上の3つ（アクセシビリティ・パスワードの入力中・トラックパッド）のどれかが出ていないか確かめます
- 2回目のカチッと感じるまで強く押し込み、そのまま少し止めているか確かめます。1回目のカチッ（ふつうのクリック）で止めると、0.6秒でふつうのクリックとして渡します（「基本の使い方」の「[開く](#開く)」）
- **システム設定 › トラックパッド** の「強めのクリックと触覚フィードバック」がオンか確かめます（オフだと設定の「一般」に知らせが出ます）。感圧タッチではないトラックパッドでは開きません
- 設定のウィンドウなど、Nonet のウィンドウが前面にあるときは、強く押し込んでも9マスは開きません（設定では、マスのドラッグなどにトラックパッドを使うため）。先に使いたいアプリに切り替えるか、設定の中で試すときは、インスペクタの「このマスをテスト実行」を使います。設定のウィンドウを閉じると、その前に使っていたアプリが前面に戻ります

### メニューバーにアイコンが見えない

メニューバーに項目が多いと、Nonet のアイコンが隠れることがあります。アプリケーションフォルダから Nonet をもう一度開くと、すぐに設定のウィンドウが開きます。アイコンが隠れている間は、メニューバーを指す通知（試用期間の終了など）の代わりにアプリケーションフォルダから開くように言い、アップデートが見つかったときも、アイコンの印ではなく、すぐに知らせを出します。

### 開くつもりがないのに開く

強めにクリックする癖があると、ふつうにクリックしたつもりでも、2回目のカチッまで押し込んで止めたときに9マスが開きます。開いてしまったら、そのまま指を離せば何も実行しません（開いた瞬間は、ポインタを真ん中から動かすまで、いつも「離すとやめる」の状態です）。そのときのクリックはアプリに届かないので、もう一度クリックし直してください。よく起きるときは、設定の「一般」の「開きやすさ」を「控えめ」（0.5秒止めたときだけ開く）にするか、**システム設定 › トラックパッド** の「クリック」の強さを「強い」にしてください（開いてすぐ指を離して閉じることが10分のうちに3回続くと、一度だけ画面の下にそう出ます）。Nonet を使わないアプリでは、Nonet のメニューの「このアプリでは使わない」を選んでおくと開かなくなります。

### ポインタが動かない・クリックが効かない

9マスを開いている間は、クリックとスクロールを前面のアプリに渡していません。開いたままと判断されているときは、次のどれかで戻ります。

- トラックパッドから指をすべて離す
- 何かキーを押す（その場で閉じます）
- マウスを動かすかクリックする（その操作はそのままアプリに届きます）
- 20秒待つ（長すぎる操作は自動で終わります）
- それでも戻らなければ、Nonet のメニューの「終了」

### 狙ったマスと違うものが実行される

マスは真ん中から見た**ポインタの向き**で決まります。HUD で白い円に乗っているアイコンを確かめてから離してください。狙いと違うアイコンに乗っていたら、指を滑らせて選び直すか、アイコンの輪の外まで動かして離せば何も実行しません。取り消せない操作のマスは、「少し長く止めてから実行」にしておくと安心です（「基本の使い方」の「[少し長く止めるマス](#少し長く止めるマス)」）。メニューの「最近の実行」で、何が実行されたかを確かめられます。

キー入力のマスで「前面のアプリが変わったため、キーを送りませんでした」と出たときは、9マスを開いてからキーを送るまでの間に、別のアプリが前面に出ていました（前のマスで開いたアプリが前に出てきたときなど）。別のアプリにキーが届かないよう、何も送っていません。使いたいアプリを前面にしてから、もう一度実行してください。メニュー項目のマスは、このときはキーを送らずにメニューを押します。

### スクリプトが失敗する

- 画面に出たエラーを確かめます（エラー出力に何も書かずに失敗したときは、標準出力の最後の部分が出ます）。画面の下の通知が消えたときは、Nonet のメニューの「最近の実行」で失敗したもの（「✗」）を選ぶと、理由の全文が結果のパネルに出ます。終了コード 127（`command not found`）なら、ターミナルで `command -v <名前>` を実行して、インストールされているかを確かめてください。裏で動くスクリプトはターミナルと同じ `PATH` を使います（Nonet の起動時に調べるので、`~/.zshrc` を変えたら Nonet を開き直してください）
- ターミナルで `zsh -lic '<スクリプト>'` を実行すると、近い条件で試せます
- インスペクタの「このマスをテスト実行」で、結果をその場で確かめられます
- 時間がかかる処理は、「制限時間」を延ばすか「ターミナルで実行」にしてください。止まらないときは、Nonet のメニューの「実行中の「◯◯」を止める」で止められます

### オートメーションの許可を求められた

スクリプトに `NONET_BROWSER_URL` が書かれていて、対応しているブラウザ（Safari・Google Chrome・Arc・Microsoft Edge・Brave）が前面にあるとき、Nonet は実行の直前に、そのブラウザに表示中のページの URL を問い合わせます。初めてのときに macOS が、Nonet にそのブラウザの操作を許可するか確かめます。URL を使うなら許可して、もう一度実行してください。許可しなくても、スクリプトは `NONET_BROWSER_URL` がないまま実行されます。

ファイルのアクションを初めて使うときは、Nonet に Finder の操作を許可するか確かめます。Finder で選んでいるファイルを読み、ゴミ箱に入れる・名前を変更・複製をするために使います。許可しなければ、ファイルのマスは「オートメーション（Finder）の許可が必要です」と表示して何もしません。

拒否した後に使いたくなったら、**システム設定 › プライバシーとセキュリティ › オートメーション** で、Nonet の下のブラウザや Finder をオンにします。

### 「画面収録」の一覧に Nonet がある

前の版には、HUD の下の画面の明るさに合わせてアイコンの色を変える設定があり、そのために macOS の「画面収録」の許可を求めていました。今の Nonet はアイコンを暗い台に白で描くので、この許可を使いません。**システム設定 › プライバシーとセキュリティ › 画面収録とシステムオーディオ録音**（macOS 14 では「画面収録」）で Nonet をオフにするか、一覧から取り除いてかまいません。

### メニュー項目のアクションが失敗する

- 対象のアプリが起動しているか確かめます
- アプリのアップデートや macOS の言語の変更で、メニューの名前が変わっていないか確かめます。変わっていたら「メニューから割り当て」で割り当て直してください

### AI のアクションが使えない

macOS 26 以降か、Apple Intelligence がオンでモデルのダウンロードが終わっているか、Mac が Apple Intelligence に対応しているかを確かめてください。理由はインスペクタの AI の欄にも出ます。テキストを選んでから実行してください。

### 選択中のテキストを読めない

AI・ショートカット・スクリプトに選択中のテキストを渡すとき、アプリが選択範囲を直接知らせなければ、Nonet は ⌘C でコピーして読み、クリップボードを元に戻します。AI のアクションで読めなかったときは、理由に合わせて次のように出ます（ショートカットとスクリプトには、選択中のテキストを渡さずに実行します）。

- 「テキストを選択してから実行してください」: テキストを選んでから、もう一度実行します。VS Code・Cursor・Obsidian・JetBrains の IDE・Sublime Text では、何も選んでいないと ⌘C で行が丸ごとコピーされるので、改行で終わる1行だけが取れたときは選択なしとみなします（「1行だけを使うときは、行末の改行を含めずに選択してください。」と出ます）
- 「クリップボードの中身を保てないため、選択テキストを読めませんでした。…」: 元に戻せないものがクリップボードにあるので、⌘C を送りませんでした（64 MB より大きい、貼り付けたときに作られるファイル、コピーした元のアプリが時間内に中身を渡さない など）。選んだテキストを自分で ⌘C でコピーしてから、もう一度実行します
- 「Nonet がクリップボードを読むことが許可されていないため、選択テキストを読めませんでした。…」: macOS がクリップボードを読ませない設定になっています（下）。**システム設定 › プライバシーとセキュリティ** で Nonet に許可します

macOS 15.4 以降で、クリップボードを読む前に確かめる設定のときは、Nonet がクリップボードを読もうとすると、macOS がほかのアプリからのペーストを許可するか確かめることがあります。20秒のうちに答えてください。いつも拒否する設定なら、Nonet はクリップボードを読みも戻しもしません。⌘C で選択中のテキストを読むことはせず、「選択範囲を置き換える」は結果のパネルに出します。

- パスワード管理アプリでコピーしたパスワードは、読みも戻しもしません
- ⌘C を送っても何もコピーされなかったときは、遅れてコピーするアプリのために0.5秒だけ待ちます。その間にコピーされたものは、そのアプリがまだ前面にあるときだけ元に戻します。その後にあなたが自分でしたコピーを戻すことはありません

### 振動しない

設定の「触覚」がオフになっていないか確かめます。振動は感圧タッチ（Force Touch）のトラックパッドでだけ感じられます。

### ログイン時に起動しない

「ログイン時に起動」（初回の案内の「Mac にログインしたら Nonet を自動で起動する」も同じ）をオンにしたとき、macOS の確認が要ることがあります。**システム設定 › 一般 › ログイン項目**（macOS 15 以降は「ログイン項目と機能拡張」）で Nonet を許可してください。

### 「設定ファイルが壊れていたため読み込めませんでした」と出る

設定のファイルが壊れていたので、最初の設定で始めました。元のファイルは、知らせに出た名前で同じフォルダ（`~/Library/Application Support/Nonet/`）に残っています。「以前の設定に戻す…」に控えがあれば、そこから戻せます。書き出しておいたファイルがあれば、「読み込む…」でも戻せます。知らせは Nonet のメニューの「この知らせを消す」で消せます。

### 設定を最初に戻したい

Nonet を終了してから `~/Library/Application Support/Nonet/` をゴミ箱に入れ、もう一度起動すると、初回の状態から始まります。試用期間の残り日数とライセンスの登録は、そのまま残ります。少し前の設定に戻したいだけなら、「以前の設定に戻す…」を使います。

## アンインストール

1. 設定の「Nonet」のタブで「Nonet をアンインストール…」を押し、「アンインストール」を押します。ログイン時の起動を止め、Nonet 本体と設定のフォルダ（`~/Library/Application Support/Nonet/`）とキャッシュをゴミ箱に入れます。ライセンスキーと試用の記録は残るので、入れ直せば登録し直さずに使え、試用期間もやり直しにはなりません。ゴミ箱を空にするまでは元に戻せます
2. 「システム設定を開いて終了」を押すと、システム設定が開いて Nonet が終わります。**プライバシーとセキュリティ › アクセシビリティ** の一覧で Nonet を選び、「−」で外します。ターミナルで `tccutil reset Accessibility com.iam74k4.Nonet` を実行しても同じです

Nonet 本体をゴミ箱に入れられなかったときは、何も変えずに知らせます。Nonet を終了してから、Finder でアプリケーションフォルダの Nonet をゴミ箱に入れてください。

ライセンスキーと試用の記録まで消すときは、Nonet を終了してから次のものも消します。

- `~/Library/Preferences/com.iam74k4.Nonet.plist`（試用の記録・ライセンスキーなどの環境設定）
- キーチェーンアクセスで `com.iam74k4.Nonet.license.trial` を検索し、見つかった項目（試用の記録）
- キーチェーンアクセスで、名前が64桁の16進数（0〜9 と a〜f）の項目（同じ試用の記録の写し。名前はこの Mac とアプリから作ったもので、Nonet の名前は付いていません）

ライセンスを別の Mac で使うなら、消す前にライセンスキーを控えておきます（設定の「Nonet」のタブの「キーをコピー」）。
