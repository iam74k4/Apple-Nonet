## Nonet とは

キーを押している間だけ、MacBook のトラックパッドが「アプリごとに変わる 3×3 の9つのボタン」になるアプリです。

- トラックパッドを縦横3つずつに分け、**指を置いた位置**でマスが決まります（カーソルの位置は関係ありません）
- 慣れたら、キーを押してすぐタップするだけでその場で実行。迷ったときだけ、9マスの一覧（HUD）が画面に出ます
- 前面のアプリに合わせて9マスが切り替わります。1つのプロファイルに最大3ページ（27マス）まで置けます

### 動作環境

- macOS 14 Sonoma 以降（Apple シリコン・Intel）
- マルチタッチのトラックパッド: MacBook の内蔵トラックパッド、または Magic Trackpad。マウスだけの Mac では使えません
- AI のアクションだけは、macOS 26 以降で Apple Intelligence が使える Mac が必要です

## はじめに

### インストール

1. ダウンロードした `Nonet-<バージョン>.dmg` を開きます
2. `Nonet` を `Applications` フォルダへドラッグします
3. アプリケーションフォルダから Nonet を開きます

ディスクイメージの中やダウンロードしたままの場所から開くと、そこからはアップデートを入れられないため、「Nonet をアプリケーションフォルダに移しますか？」と確かめます。「アプリケーションフォルダに移す」を押すと、移してから開き直します（管理者でないアカウントでは、ホームフォルダの中の「アプリケーション」に移します）。アプリケーションフォルダにすでに Nonet があるときは、置き換えてよいかをもう一度確かめ、前の Nonet はゴミ箱に入れます。どちらのフォルダにも移せないときは、Finder で移す方法を案内します。

Nonet はメニューバーに常駐するアプリで、Dock には出ません。メニューバーの 3×3 のアイコン（中央が塗りつぶし）が Nonet です。このガイドでは、このアイコンを押すと開くメニューを「Nonet のメニュー」と呼びます。

Nonet は同時に1つしか動きません。動いているときにもう一度開くと、新しく起動する代わりに、動いている Nonet の設定のウィンドウが開きます（3秒ほどかかります）。ディスクイメージから開いた Nonet が動いているときにアプリケーションフォルダの Nonet を開くと、ディスクイメージの方が終わり、アプリケーションフォルダの方が代わりに動きます。

### アクセシビリティの許可

初めて起動すると「Nonet へようこそ」のウィンドウ（初回の案内）が開きます。「システム設定を開く」を押し、**システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet をオンにしてください。許可すると、システム設定の後ろに隠れた案内のウィンドウが自動で前に戻り、次へ進みます。

**なぜ必要か**: macOS では、ほかのアプリを使っている間のキーボードやポインタを扱うのにこの許可が要ります。Nonet は次のことにだけ使います。

- トリガーキーが押された・離されたことを知る
- トリガーキーを押している間、カーソルの移動とクリックを前面のアプリに渡さない
- 設定したキー入力を送る・メニュー項目を押す・選択中のテキストを読む

**集めないもの**: 入力した文字の内容は記録も送信もしません。設定は Mac の中（`~/Library/Application Support/Nonet/`）だけに保存し、アカウントもありません。ネットワークを使うのは、アップデートの確認と購入ページを開くときだけです。トラックパッドの指の位置を読むのに許可は要りません。詳しくは[プライバシーポリシー](privacy.md)をご覧ください。

「あとで許可する」で先へ進むこともできますが、許可するまで Nonet は動きません（案内の上に並んだ段階の「アクセシビリティ」に「!」が付きます）。あとから許可するときは、Nonet のメニューの「アクセシビリティを許可…」か、設定のウィンドウの上に出る帯の「システム設定を開く」を使います。

スクリプトでブラウザの表示中のページの URL（`NONET_BROWSER_URL`）を使うときは、macOS が初回に「オートメーション」の許可を求めます（「困ったとき」の「[オートメーションの許可を求められた](#オートメーションの許可を求められた)」）。

### 初回の案内

「Nonet へようこそ」のウィンドウは、上に並んだ3つの段階で進みます。

1. **アクセシビリティ**: 上の許可です
2. **アプリを選ぶ**: Mac に入っているアプリのうち、プリセット（最初から用意した9マス）のあるものが並びます（Xcode・Visual Studio Code・Safari・Slack・Zoom など）。最初はすべて選ばれています。使うものだけを選び、「次へ：試してみる」を押します。「すべて選ぶ」「すべて外す」でまとめて切り替えられます。「あとで設定する」を押すと、選ばずに先へ進みます（初めての案内では、並んだアプリをすべて使います）
3. **試してみる**: 練習モードです。案内のとおりに、トリガーキーを押しながらトラックパッドの右上をタップします。練習中は、マスを押しても何も実行されません。「スキップ」で飛ばせます。試せないときは、理由と直すためのボタンが出ます。Nonet が無効なら「Nonet を有効にする」、試用期間が終わっていれば「ライセンスキーを入力…」（ライセンスキーを登録すると、この知らせは消えます）

最後に「準備ができました」と、使い方のこつが3つ出ます。「完了」で閉じます。「設定を開く」を押すと、そのまま設定のウィンドウが開きます。

グローバルのプロファイルには、Mac にあるよく使うアプリを並べたランチャーが入ります（「基本の使い方」の「[グローバルとランチャー](#グローバルとランチャー)」）。

案内は Nonet のメニューの「初回の案内をもう一度」で何度でも見られます。もう一度見たときの「アプリを選ぶ」は、選んだアプリのプロファイルを追加するだけです。「設定済み」の印が付いたアプリはそのまま残り、編集した中身が消えることはありません。

## 基本の使い方

### トリガーキー

9マスにするためのキーです。既定は、JIS 配列のキーボードなら**右⌘**、それ以外なら**右⌥**です（JIS 配列には右⌥がありません）。設定で右⇧や fn（地球儀）にも変えられます。右側のキーだけに反応するので、左の⌘や⌥はいつもどおり使えます。

以下は右⌘の例です。

### 速押し（慣れたら）

1. 右⌘を押します
2. すぐに（既定では0.3秒以内に）実行したいマスの位置をタップします

HUD は出ずに、その場で実行されます。実行したマスは画面の下に一瞬表示されます。右⌘を押したままなら、何度でも続けてタップできます。

### HUD（迷ったら）

1. 右⌘を押します
2. 指をトラックパッドに置いたまま止めます（または、指を置かずに少し待ちます）
3. 9マスの HUD が出て、指の下のマスが白く光ります。指を滑らせて選びます
4. 指を置いたまま右⌘を離すと、光っているマスが実行されます

HUD の上には、プロファイルの名前と「⌘を離して実行」の案内が出ます。HUD はカーソルのあるディスプレイに出ます。

設定の「実行のタイミング」を「指を離したとき」にすると、4 の代わりに、マスから指を離した時点で実行します（案内は「指を離して実行」）。このときは、やめ方も変わります（次の「やめる」）。

### やめる（キャンセル）

どの設定でも:

- 指を置かずに右⌘を離せば、何も起きません
- 右⌘を押している間にほかのキーを押すと、Nonet はすぐに引っ込み、何も実行しません。そのキーは普段どおりアプリに届きます（右⌘＋C なども普段どおり使えます）。やめるためだけに押すなら、**左の⇧**のように、単独で押しても何も起きない修飾キーが安全です

「実行のタイミング」によって:

- **「キーを離したとき」（既定）**: 指を先に離してから右⌘を離すと、何も実行しません
- **「指を離したとき」**: 指を離すと、その時点で光っているマスが実行されます。HUD で選んでいる途中でやめるときは、**指を置いたまま左の⇧を押す**か、空きマスがあれば、そこまで指を滑らせてから離します（空きマスでは何も起きません）

### 押している間のトラックパッド

右⌘を押している間はカーソルが止まり、クリックやスクロールも前面のアプリに届きません。2本以上の指で触れたタップは実行しません。空きマスをタップしても何も起きません。右⌘を押したまま20秒たつと、Nonet は自動で引っ込みます。

### ページ

右⌘を押したまま、**2本指で左右にスワイプ**すると前後のページに切り替わります。2本指を左へ動かすと次のページです。1回のスワイプで1ページ進み、端では止まります。HUD が出ていなければ、このとき出ます。HUD の下の点が今のページを示します。

1つのプロファイルに最大3ページまで置けます。アプリのプロファイルの後ろには、グローバルのページがつながります（設定の「グローバルのページをつなげる」）。

### グローバルとランチャー

前面のアプリにプロファイルがあれば、そのアプリの9マスを使います。プロファイルの無いアプリの前では、どのアプリでも使える「グローバル」のプロファイルを使います。

グローバルのプロファイルは、最初はよく使うアプリを最大27個（3ページ）並べたランチャーです。Mac に入っているアプリから選んで並べます。macOS 26 で無くなった Launchpad の代わりに使えます。中身はほかのプロファイルと同じように自由に変えられます。

### 触覚

指がマスの境界をまたぐたびに、トラックパッドが軽く「コツッ」と振動します。ページが変わったときと実行したときにも振動します。強さは設定の「触覚」で選べます。

## メニューバー

メニューバーの 3×3 のアイコンを押すと、Nonet のメニューが開きます。

| 項目 | 内容 |
|---|---|
| 状態（いちばん上の行） | 動作中なら「Xcode のプロファイル」「グローバルのプロファイル」のように、前面のアプリで使うプロファイルを表示します。問題があれば「アクセシビリティの許可が必要です」「トラックパッドが見つかりません」「パスワード入力中は使えません」「Nonet は無効です」などを表示します |
| アクセシビリティを許可… | 許可が無いときだけ出ます。システム設定のアクセシビリティの欄を開きます |
| この知らせを消す | 設定ファイルを読めなかったときなどに、知らせと一緒に出ます |
| Nonet を有効にする | チェックを外すと、トリガーキーに反応しなくなります |
| 設定… | 設定のウィンドウを「一般」のタブで開きます |
| プロファイルを編集… | 設定のウィンドウを「プロファイル」のタブで開きます |
| 初回の案内をもう一度 | 「Nonet へようこそ」のウィンドウを開きます |
| 試用期間: 残り 14 日 / 登録済み / 試用期間が終了しました | ライセンスの状態です。選ぶと、設定のウィンドウを「ライセンス」のタブで開きます |
| アップデートを確認 | 新しい版があるか確かめます。自動の確認で新しい版が見つかっているときは「アップデートがあります…」に変わり、選ぶとその知らせを出します |
| 終了 | Nonet を終了します |

アイコンの見た目でも状態が分かります。無効のときは薄くなり、確かめてほしいことがあるとき（許可が無い・トラックパッドが見つからない・パスワードの入力中・試用期間の終了・知らせがある）は右上に点が付きます。新しい版が見つかったときも点が付きます。

## プロファイルを編集する

Nonet のメニューの「プロファイルを編集…」で、設定のウィンドウの「プロファイル」のタブを開きます。左から、プロファイルの一覧・9マス・インスペクタの3つの列に分かれています。

### プロファイルの一覧

- いちばん上の「グローバル」（「既定」の印）は、プロファイルの無いアプリで使う9マスです。消すことはできません
- その下の「アプリ」に、アプリのプロファイルが並びます。ドラッグで並べ替えられます
- 「プロファイルを追加」で、インストール済みのアプリから選んで作ります。プリセットのあるアプリは、最初から中身が入ります。一覧に無いアプリは「一覧に無いアプリを選ぶ…」で選べます
- プロファイルを右クリック（Control キーを押しながらクリック）すると、「無効にする」「このプロファイルを書き出す…」「削除…」が出ます。Delete キーでも削除できます。削除する前に確かめます（元に戻せません）
- 無効にしたプロファイルには「オフ」の印が付き、そのアプリの前でもグローバルを使います。9マスの右上の「このプロファイルを使う」でも切り替えられます
- 一覧の下の「Nonet を有効にする」は、一般の設定と同じスイッチです

### ページと9マス

中央に、選んだプロファイルのページと 3×3 のマスが出ます。

- 「ページ 1」「ページ 2」…で切り替えます。「＋」（ページを追加）で増やし（最大3ページ）、「−」（このページを削除）か、ページを右クリックして「このページを削除…」で消します
- マスをクリックで選び、ドラッグで入れ替えます。「ページ 2」などの上へドラッグすると、そのページの空きマスへ移ります
- 矢印キーで選ぶマスを移り、Delete キーで空にします
- マスを空にする・削除・複製・作る・入れ替える・ほかのページへ移す・メニューから割り当てるといった変更は、⌘Z で元に戻せます（⇧⌘Z でやり直し）。マスを空にしたときと、中身のあるマスをメニュー項目で置き換えたときは、9マスの下に出る「元に戻す」でも戻せます。その後でまた変えたマスは、元に戻さずにそう知らせます。ページやプロファイルの削除と、読み込みでの置き換えは元に戻せません
- マスを右クリックすると「複製」「削除」「このマスをテスト実行」が出ます。空きマスでは「アクションを追加」から種類を選んで作れます

### インスペクタ

右の列で、選んだマスを設定します。変更はその場で保存されます。

- **空きマス**: アクションの種類のボタンを押して作ります
- **表示名**: マスの下に出る名前です。空のときは、中身から自動で付けた名前を使います
- **アイコン**: 表示名の左のアイコンを押して選びます。「記号」（SF Symbols。英語の名前で検索します）・「アプリ」（「このアプリのアイコンを使う」。アプリ起動のマスか、アプリのプロファイルで使えます）・「文字」（1〜2文字を入れて「使う」）。「既定のアイコンに戻す」で元に戻ります
- **アクションの種類**: キー入力・アプリ起動・URL・スクリプト・ショートカット・メニュー項目・AI（次の「アクションの種類」）
- **このマスをテスト実行**: その場で実行して、「実行しました」かエラーを表示します。アプリのプロファイルでは、そのアプリを前面に出してから実行します。グローバルのマスは、設定を開く前に使っていたアプリの前で実行します
- **このマスを空にする**: 中身を消して空きマスに戻します

### メニューから割り当て

ショートカットを調べなくても、アプリのメニューから選んで割り当てられます。

1. 対象のアプリを起動しておきます
2. 9マスの右上の「メニューから割り当て」を押し、ポップアップメニューからアプリを選びます
3. 「メニューを検索」で探し、項目を空いているマスへドラッグします。ダブルクリックか、右クリックの「空いているマスに入れる」でも入ります

インスペクタに戻るときは、パネルの右上の「×」（インスペクタに戻る）を押します。

## アクションの種類

### キー入力

前面のアプリにキーを送ります。「送るキー」の欄（「クリックして記録」）を押してから、送りたいキーをそのまま押すと記録されます。

- `⌘B`、`⇧⌘4` のような組み合わせ
- `⌘L → ⌘C` のような、続けて押すキー（4つまで。40ミリ秒の間隔で送ります）

記録しているとき（欄に「キーを押してください…」と出ている間）は、次のように動きます。

- 続けて押すと連続キーになります。Return や Tab もそのまま記録します
- 「完了」を押すか、ほかの場所をクリックすると決まります。4つ押したときも決まります
- Esc を押すと、何も変えずに記録をやめます（「やめる」も同じ）。Esc キーそのものを送りたいときは「Esc を加える」を押します
- 押し間違えたキーは、⌫（最後のキーを消す）で消せます

⌘Tab・⌘Space やスクリーンショットの ⇧⌘4 のように、macOS が先に使うキーは記録欄に届きません。そのときは、記録欄の下の「表記で入力」の欄にキーを書いて「決定」を押します。`⇧⌘4` のような記号のほか、`cmd+shift+4` のような書き方も読めます。続けて押すキーは `→` か `,` で区切ります。

JIS 配列でも、`⌘[` などが正しく届きます。

### アプリ起動

起動していなければ起動し、起動中なら前面に出します。「開くアプリ」の「アプリを選ぶ…」で、インストール済みのアプリから選びます。一覧に無いアプリは「一覧に無いアプリを選ぶ…」で選べます。

「前面のときは隠す」をオンにすると、もう一度押したときに隠れるので、アプリの切り替えのように使えます。

### URL

「開く URL」を既定のアプリで開きます。`https://` を省いた場合は自動で補います（`localhost` などは `http://`）。`obsidian://` のような、アプリ独自の URL も使えます。`/` や `~` で始めると、ファイルやフォルダとして開きます。

### スクリプト

「実行するスクリプト（zsh）」の欄に書いた zsh のスクリプトを実行します（`/bin/zsh -l -c`）。欄の右上の「?」を押すと、下の環境変数の説明が出ます。

- **実行の仕方**
  - 裏で実行: 終わるまで待ちます。「制限時間」（既定 60秒、1〜3600秒）を過ぎると止めます。失敗したら（終了コードが 0 以外）、エラー出力の最後の部分を画面に表示します
  - ターミナルで実行: ターミナルの新しいウィンドウで実行します。`claude` のような対話型のコマンドに向いています
- **作業フォルダ**: プロジェクトのフォルダ（下記）。分からなければホームフォルダ
- **環境**: ログインシェルなので `~/.zprofile` は読まれますが、`~/.zshrc` は読まれません。Homebrew などの `PATH` は `~/.zprofile` に書いてください

#### スクリプトに渡す環境変数

実行したときの前面のアプリの情報を渡します。**値が無いものは設定されません**。

| 変数 | 中身 | 例 |
|---|---|---|
| `NONET_APP_BUNDLE_ID` | 前面のアプリの bundle ID | `com.apple.dt.Xcode` |
| `NONET_APP_NAME` | 前面のアプリの名前 | `Xcode` |
| `NONET_DOCUMENT_PATH` | 前面のウィンドウで開いている書類 | `/Users/you/dev/App/App.xcodeproj` |
| `NONET_PROJECT_DIR` | 書類から決めたプロジェクトのフォルダ | `/Users/you/dev/App` |
| `PROJECT_DIR` | `NONET_PROJECT_DIR` と同じ | `/Users/you/dev/App` |
| `NONET_BROWSER_URL` | ブラウザで表示中のページ（Safari・Google Chrome・Arc・Microsoft Edge・Brave） | `https://example.com/article` |
| `NONET_SELECTED_TEXT` | 選択中のテキスト | |

選択中のテキスト（`NONET_SELECTED_TEXT`）とブラウザの URL（`NONET_BROWSER_URL`）は、スクリプトにその変数の名前が書かれているときだけ読みます（読むために ⌘C を送ったり、ブラウザに問い合わせたりするため）。名前が書かれていないスクリプトでは、⌘C を送らず、ブラウザにも問い合わせません（オートメーションの確認も出ません）。選択中のテキストを直接読めないアプリでは、⌘C でコピーして読み、クリップボードは元に戻します。別のファイルのスクリプトを呼ぶだけのときは、コメントでよいので、使う変数の名前を書いておいてください（下の例）。ほかの変数（`NONET_APP_BUNDLE_ID`・`NONET_APP_NAME`・`NONET_DOCUMENT_PATH`・`NONET_PROJECT_DIR`・`PROJECT_DIR`）は、値があればいつも設定します。

プロジェクトのフォルダは次のように決めます。

- 書類が `.xcodeproj`・`.xcworkspace`・`.swiftpm` なら、その入っているフォルダ
- ほかのファイルなら、上へたどって `.git` か `Package.swift` のあるフォルダ。見つからなければ、そのファイルのあるフォルダ
  - ホームフォルダの中では、ホームフォルダの手前までたどります（何段でもたどるので、Maven・Gradle・Android のような深いフォルダでも見つかります）
  - ホームフォルダの外（`/Volumes/SSD` など）では、書類から上へ32個のフォルダまでです。`/` や `/Volumes` のような、いちばん上のフォルダは調べません
  - ネットワーク上の場所の書類では探さず、そのファイルのあるフォルダを使います
  - 0.3秒のうちに調べ終わらないとき（眠っている NAS など）は、プロジェクトのフォルダは無しになり、スクリプトはホームフォルダで動きます

例:

```zsh
# Claude Code をプロジェクトのフォルダで開く（「ターミナルで実行」）
cd "$PROJECT_DIR" && claude

# プロジェクトを VS Code で開く
open -a "Visual Studio Code" "${PROJECT_DIR:-$HOME}"

# 表示中のページの URL をクリップボードへ
printf '%s' "${NONET_BROWSER_URL:?ブラウザが前面にありません}" | pbcopy

# 選択中のテキストを別のファイルのスクリプトに渡す（このコメントに NONET_SELECTED_TEXT と書いてあるので読みます）
~/bin/translate.sh
```

変数は必ず `"$NONET_SELECTED_TEXT"` のように `"` で囲んでください（空白や記号を含むことがあります）。無いかもしれない変数は `${変数:-既定値}` か `${変数:?メッセージ}` で扱うと安全です。`:?` のメッセージは失敗として画面に出ます。

### ショートカット

ショートカット.app のショートカットを実行します。「実行するショートカット」に名前を入れるか、横の一覧のボタン（ショートカットの一覧から選ぶ）から選びます。「選択中のテキストを渡す」をオンにすると、選択中のテキストを入力として渡します。

### メニュー項目

アプリのメニュー項目を押します。「メニューから割り当て」で選ぶのがかんたんです（インスペクタの「メニューから選ぶ…」でも開きます）。「押すメニュー項目」に、項目の場所・アプリ・キーが出ます。

- 対象のアプリが前面にあり、その項目にキー（ショートカット）があれば、キーを送ります（速い）
- キーが無ければ（「なし（メニューを順にたどって押します）」）、アクセシビリティの機能でメニューを順にたどって押します
- 「再生」⇄「一時停止」や「ツールバーを表示」⇄「ツールバーを非表示」のように、押すと名前が変わる項目も、続けて使えます。名前が見つからなければ対になる名前で探し、それでも無ければ、同じメニューに同じキー（ショートカット）の項目が1つだけならそれを押します
- 対象のアプリが起動している必要があります
- メニューの名前は macOS の言語で変わります。言語を変えたら割り当て直してください

### AI

選択中のテキストと「指示文」を、Mac の中の言語モデル（Apple Intelligence）に渡します。テキストが Mac の外に送られることはありません。

- 必要なもの: macOS 26 以降、Apple Intelligence に対応した Mac、**システム設定 › Apple Intelligence と Siri** で Apple Intelligence をオン（モデルのダウンロードが終わっていること）
- 結果の出し方:
  - 選択範囲を置き換える: 選択中のテキストを結果で置き換えます（クリップボードを通して ⌘V で貼り付け、クリップボードは元に戻します）。待っている間に前面のアプリが変わったときは、代わりにクリップボードにコピーします。アプリが選択範囲を知らせず ⌘C で読んだとき（貼り付けると、カーソルの位置に入ってしまうことがあるため）と、クリップボードの中身を元に戻せないとき（下の「[選択中のテキストを読めない](#選択中のテキストを読めない)」）は、貼り付けずに結果のパネルに出します
  - クリップボードにコピー
  - 画面に表示: 結果のパネルに出します。文を選んでコピーすることもできます。「コピー」で結果をコピーし、「閉じる」か Esc でパネルを閉じます
- 使えない Mac では、インスペクタと実行したときに理由を表示します
- クリップボードを元に戻すとき、コピーしてあった画像は1つの形式だけを、Finder でコピーしたファイルはファイルだけを（アイコンの絵は除いて）戻します

### 書き出しと読み込み

プロファイルを `.nonetprofile` のファイルに書き出して、バックアップしたり、別の Mac やほかの人と共有したりできます。書き出すのはプロファイル（9マスの中身）だけで、一般の設定やライセンスは含みません。

- **書き出す…**: すべてのプロファイルを1つのファイルに書き出します。1つだけ書き出すときは、プロファイルの一覧で右クリックして「このプロファイルを書き出す…」を選びます
- **読み込む…**: ファイルのプロファイルを加えます。次のどちらかに当たるときは、先に「「ファイル名」を読み込みますか？」と確かめます
  - 今の設定が置き換わる（ファイルにグローバルが入っている、または同じアプリのプロファイルがすでにある）: 置き換わるものを並べます
  - 何かを実行するマスがある（スクリプト、Return を押すか5つ以上続けて押すキー入力、Mac の中のファイルを開く URL）: 何も置き換わらなくても確かめます。「・プロファイル › マス」ごとに、スクリプトの最初の3行と行数・押すキー・開くファイルの場所を見せます

確かめるときは、中身を見て次のどれかを選びます。

- 置き換えて読み込む: 置き換わるものがあるときに出ます。一覧のものをファイルの中身で置き換え、新しいアプリのプロファイルも加えます。元に戻せません
- 読み込む: 置き換わるものが無いときに出ます。ファイルのプロファイルを加えます
- 新しいプロファイルだけ追加: 今のプロファイルには触れず、まだ無いアプリのプロファイルだけ加えます（置き換わるものと、加えるものの両方があるときだけ出ます）
- キャンセル: 何も変えません

どちらにも当たらなければ、確かめずにそのまま加えます。結果（追加した数・置き換えた数・読み込まなかった数）は、ウィンドウの上の帯に出ます。メニュー項目のマスのキー（ショートカット）は1つのキーだけを読み込みます。それより長いものは捨て、その項目はメニューを順にたどって押します。

**ほかの人から受け取ったプロファイルは、信頼できるものだけを読み込んでください**（スクリプトやキー入力はあなたの権限で動きます）。読み込む前の確認でマスの中身を確かめ、スクリプトの全体は、読み込んだ後にインスペクタで読めます。スクリプトを含むときは、読み込んだ後の帯でも知らせます。

## 試用とライセンス

- 初めて起動した日から**14日間**、すべての機能を無料で使えます。残り日数は Nonet のメニューと、設定の「ライセンス」のタブに出ます
- 試用期間が終わると、HUD に「試用期間が終了しました」と表示され、マスを押しても実行されません。設定はそのまま残ります
- 購入すると、ライセンスキーがメールで届きます

「ライセンス」のタブ:

- **状態**: 「試用期間中（残り 14 日）」「登録済み」「試用期間が終了しました」のどれかです。登録済みなら、登録者・発行日・ライセンス ID も出ます
- **ライセンスキー**: 購入時のメールに書かれたライセンスキーを欄に貼り付けて「登録」を押すと、すぐに使えるようになります。「License key:」のような前後の文字ごと貼り付けても、キーの部分だけを読みます。キーはこの Mac の中で確かめるので、ネットワークもアカウントも要りません
- **購入する**: 購入ページを開きます（登録していないときだけ出ます）
- **この Mac での登録を外す**: 「登録を解除…」を押し、確かめてから「登録を解除」を押すと、この Mac からライセンスキーを消します。別の Mac に移すときなどに使います。ライセンスキーを控えておけば、また登録できます

## アップデートと情報

新しい版は自動で確認されます。見つかると、メニューバーのアイコンに点が付き、Nonet のメニューの「アップデートを確認」が「アップデートがあります…」に変わります。選ぶと、新しい版の知らせが出ます（起動した直後に見つかったときは、すぐに知らせが出ます）。Nonet のメニューの「アップデートを確認」で、いつでも確認できます。

設定の「情報」のタブには、バージョン・「アップデートを確認」・「利用ガイド」（このガイド）・「プライバシー」（プライバシーポリシー）と、Nonet が使っているサードパーティのソフトウェアのライセンスがあります。Nonet を英語で使っているときは、利用ガイドとプライバシーポリシーは英語のページが開きます。

## 困ったとき

Nonet が動けないときは、Nonet のメニューのいちばん上の行と、設定のウィンドウの上の帯に理由が出ます。

### 「アクセシビリティの許可が必要です」と出る

- 設定のウィンドウの上の帯の「許可を求める」か「システム設定を開く」、または Nonet のメニューの「アクセシビリティを許可…」を押します
- **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet をオンにします。許可されると自動で動き出します
- オンになっているのに効かないとき（アップデートの後など）は、一覧から Nonet を選んで「−」で外し、もう一度追加してオンにしてください

### 「パスワードの入力中は動きません」と出る

パスワード欄にカーソルがあるときや、ターミナルの「セキュアキーボード入力」がオンのとき、macOS はほかのアプリにキーを見せません。パスワード欄から離れるか、ターミナル › セキュアキーボード入力 をオフにしてください。離れると自動で戻ります。帯の「もう一度確かめる」ですぐに確かめ直せます。

### 「トラックパッドが見つかりません」と出る

MacBook の内蔵トラックパッドか Magic Trackpad が必要です。マウスだけでは使えません。Magic Trackpad をつないだり、つなぎ直したりしたときは、Nonet が自動で見つけ直します（10秒ほどかかることがあります）。帯の「もう一度確かめる」で、すぐに確かめ直すこともできます。それでも反応しないときは、Nonet のメニューの「終了」で Nonet を終了し、もう一度起動してください。

### まったく反応しない

- Nonet のメニューの「Nonet を有効にする」にチェックが付いているか確かめます
- 試用期間が終わっていないか確かめます（Nonet のメニューに「試用期間が終了しました」と出ます）
- トリガーキーが設定のとおりか確かめます。左の⌘や⌥には反応しません
- 上の3つ（アクセシビリティ・パスワードの入力中・トラックパッド）のどれかが出ていないか確かめます
- 設定のウィンドウなど、Nonet のウィンドウが前面にあるときは、キー入力・スクリプト・ショートカット・メニュー項目・AI のマスは実行せず、「Nonet のウィンドウが前面にあるので実行しませんでした。…」と知らせます（アプリ起動と URL のマスは実行します）。先に使いたいアプリに切り替えるか、設定の中で試すときは、インスペクタの「このマスをテスト実行」を使います。設定のウィンドウを閉じると、その前に使っていたアプリが前面に戻ります

### メニューバーにアイコンが見えない

メニューバーに項目が多いと、Nonet のアイコンが隠れることがあります。アプリケーションフォルダから Nonet をもう一度開くと、少しして（3秒ほど）設定のウィンドウが開きます。

### カーソルが動かない・クリックが効かない

トリガーキーを押している間は、カーソルとクリックを止めています。キーが押されたままと判断されているときは、次のどれかで戻ります。

- トリガーキー（右⌘など）を一度押して離す
- 何かほかのキーを押す（その場で中断されます）
- 20秒待つ（長すぎる操作は自動で終わります）
- それでも戻らなければ、Nonet のメニューの「終了」

押している間にカーソルが少し動いてしまうときは、設定の「詳細」の「カーソルの固定方法」を変えてみてください。

### JIS キーボードで右⌥が見つからない

JIS 配列には右⌥がありません。トリガーキーを右⌘（既定）・右⇧・fn のどれかにしてください。

### 右⌘の単押しを使うツールと重なる

⌘英かな や Karabiner-Elements などで「右⌘の単押し」を使っている場合、Nonet を使うたびにそちらも反応することがあります。トリガーキーを別のキーにするか、そのツールの設定を変えてください。設定の「トリガーキーを前面のアプリに渡す」をオフにすると、ほかのアプリやツールにトリガーキーが届かなくなります。

### タップしたマスと違うものが実行される

マスはトラックパッドの**絶対的な位置**で決まります。端のマスはトラックパッドの端の方をタップしてください。迷ったら指を置いて止まり、HUD で確かめてから実行できます。速押しが速すぎて HUD が出る、または遅すぎて HUD が出ないと感じたら、「HUD が出るまでの時間」を変えてください。

### スクリプトが失敗する

- 画面に出たエラーを確かめます。`command not found` なら、`PATH` を `~/.zprofile` に書いてください（スクリプトはログインシェルで動くので、`~/.zshrc` は読まれません）。たとえば Homebrew なら `eval "$(/opt/homebrew/bin/brew shellenv)"` を `~/.zprofile` に書きます
- ターミナルで `zsh -l -c '<スクリプト>'` を実行すると、同じ条件で試せます
- インスペクタの「このマスをテスト実行」で、結果をその場で確かめられます
- 時間がかかる処理は、「制限時間」を延ばすか「ターミナルで実行」にしてください

### オートメーションの許可を求められた

スクリプトに `NONET_BROWSER_URL` が書かれていて、対応しているブラウザ（Safari・Google Chrome・Arc・Microsoft Edge・Brave）が前面にあるとき、Nonet は実行の直前に、そのブラウザに表示中のページの URL を問い合わせます。初めてのときに macOS が、Nonet にそのブラウザの操作を許可するか確かめます。URL を使うなら許可して、もう一度実行してください。許可しなくても、スクリプトは `NONET_BROWSER_URL` が無いまま実行されます。

拒否した後に使いたくなったら、**システム設定 › プライバシーとセキュリティ › オートメーション** で、Nonet の下のブラウザをオンにします。

### メニュー項目のアクションが失敗する

- 対象のアプリが起動しているか確かめます
- アプリのアップデートや macOS の言語の変更で、メニューの名前が変わっていないか確かめます。変わっていたら「メニューから割り当て」で割り当て直してください

### AI のアクションが使えない

macOS 26 以降か、Apple Intelligence がオンでモデルのダウンロードが終わっているか、Mac が Apple Intelligence に対応しているかを確かめてください。理由はインスペクタの AI の欄にも出ます。テキストを選んでから実行してください。

### 選択中のテキストを読めない

AI・ショートカット・スクリプトに選択中のテキストを渡すとき、アプリが選択範囲を直接知らせなければ、Nonet は ⌘C でコピーして読み、クリップボードを元に戻します。AI のアクションで読めなかったときは、理由に合わせて次のように出ます（ショートカットとスクリプトには、選択中のテキストを渡さずに実行します）。

- 「テキストを選択してから実行してください」: テキストを選んでから、もう一度実行します。VS Code・Cursor・Obsidian・JetBrains の IDE・Sublime Text では、何も選んでいないと ⌘C で行が丸ごとコピーされるので、改行で終わる1行だけが取れたときは選択なしとみなします（「1行だけを使うときは、行末の改行を含めずに選択してください」と出ます）
- 「クリップボードの中身を保てないため、選択テキストを読めませんでした。…」: 元に戻せないものがクリップボードにあるので、⌘C を送りませんでした（64 MB より大きい、貼り付けたときに作られるファイル、コピーした元のアプリが時間内に中身を渡さない など）。選んだテキストを自分で ⌘C でコピーしてから、もう一度実行します
- 「Nonet がクリップボードを読むことが許可されていないため、選択テキストを読めませんでした。…」: macOS がクリップボードを読ませない設定になっています（下）。**システム設定 › プライバシーとセキュリティ** で Nonet に許可します

macOS 15.4 以降で、クリップボードを読む前に確かめる設定のときは、Nonet がクリップボードを読もうとすると、macOS がほかのアプリからのペーストを許可するか確かめることがあります。20秒のうちに答えてください。いつも拒否する設定なら、Nonet はクリップボードを読みも戻しもしません。⌘C で選択中のテキストを読むことはせず、「選択範囲を置き換える」は結果のパネルに出します。

- パスワード管理アプリでコピーしたパスワードは、読みも戻しもしません
- ⌘C を送っても何もコピーされなかったときは、遅れてコピーするアプリのために0.5秒だけ待ちます。その間にコピーされたものは、そのアプリがまだ前面にあるときだけ元に戻します。その後にあなたが自分でしたコピーを戻すことはありません

### 振動しない

設定の「触覚」がオフになっていないか確かめます。振動は感圧タッチ（Force Touch）のトラックパッドでだけ感じられます。

### ログイン時に起動しない

「ログイン時に起動」をオンにしたとき、macOS の確認が要ることがあります。**システム設定 › 一般 › ログイン項目**（macOS 15 以降は「ログイン項目と機能拡張」）で Nonet を許可してください。

### 「設定ファイルが壊れていたため読み込めませんでした」と出る

設定のファイルが壊れていたので、最初の設定で始めました。元のファイルは、知らせに出た名前で同じフォルダ（`~/Library/Application Support/Nonet/`）に残っています。書き出しておいたファイルがあれば、「読み込む…」で戻せます。知らせは Nonet のメニューの「この知らせを消す」で消せます。

### 設定を最初に戻したい

Nonet を終了してから `~/Library/Application Support/Nonet/` をゴミ箱に入れ、もう一度起動すると、初回の状態から始まります。試用期間の残り日数とライセンスの登録は、そのまま残ります。

## アンインストール

1. 設定の一般のタブで「ログイン時に起動」をオフにします
2. ライセンスを別の Mac で使うなら、ライセンスキーを控えておきます
3. Nonet のメニューの「終了」
4. アプリケーションフォルダの `Nonet` をゴミ箱に入れます
5. 次のファイルとフォルダを消します
   - `~/Library/Application Support/Nonet/`（設定と試用の記録）
   - `~/Library/Preferences/com.iam74k4.Nonet.plist`（試用の記録とライセンスキー）
   - `~/Library/Caches/com.iam74k4.Nonet/`（アップデートの一時ファイル）
6. キーチェーンアクセスで `com.iam74k4.Nonet.license.trial` を検索し、見つかった項目（試用の記録）を削除します
7. **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で Nonet を選び、「−」で外します。ターミナルで `tccutil reset Accessibility com.iam74k4.Nonet` を実行しても同じです
