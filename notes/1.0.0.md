# Nonet 1.0.0

最初の版です。トラックパッドの上の縁から指を下へ滑らせると、ポインタの周りに、前面のアプリに合わせた9つのボタンが開きます。

- アプリごとに9マス×最大3ページ。左右で止めるとページ、下で止めるとグローバルのページ
- 主なアプリのプリセット、メニューからの割り当て、ランチャー、触覚、スクリプトと AI のアクション
- 14日間の試用のあと、買い切りのライセンスで使い続けられます

The first release. Slide one finger down from the top edge of the trackpad to open nine buttons around the pointer, set for the app in front.
